# S0 地基

**建议时长：1–2 个月**（可与 S1 并行）

## 阶段目标

学完你能：把"光"的各种描述方式放在同一张地图上；做任何光学计算时单位、量纲、数量级不出错；知道一次测量结果该怎么写成"值 ± 不确定度"；能打开 Python 画出第一条光路。

## 核心问题

1. 光既可以用光线描述，也可以用波描述，什么时候用哪个？
2. 亮度、照度、功率、辐亮度到底差在哪？（这是光学里最高频的混淆）
3. 一个测量结果凭什么说它"对"？
4. 我的工作台能做什么、不能做什么？

## 必推公式

- 波长↔频率↔光子能量的三种换算
- 辐照度与距离的平方反比关系及其失效条件
- 误差传递公式（和差、积商、幂函数三种情形）
- 高斯光束的基本参数关系（先知道形状，S4 再推）

## 实验

| 实验 | 产出 | 关键技能 |
| --- | --- | --- |
| 用手机/摄像头测照度—距离关系 | 一张 log-log 图 + 拟合指数 | 数据采集、幂律拟合 |
| 用现有相机拍光源的过曝光斑，估算光源尺寸 | 相对测量报告 | 图像处理、相对定标 |
| 用游标卡尺/千分尺测 20 次同一长度 | 平均值 ± 标准差 | 重复性、A 类不确定度 |
| 用手机慢动作模式观察激光散斑或激光笔的光斑结构 | 观察笔记 | 现象敏感性 |
| 把激光笔照到墙上测发散角 | θ 与厂家标称值对比 | 小角近似 |

## 仿真

- 装好 Python 环境，跑通 `numpy`/`matplotlib`。
- 写第一个脚本：二维矢量光线在平面镜上的反射（画出多面镜子组成的"光路迷宫"）。
- 画一个正弦波 + 高斯包络，理解"包络 vs 载波"。

## 阶段作品

一张 `工位全景照片` + 一份 `器材清单` + 一个能跑的 `sim/` 环境。

## 验收标准

- 能不看资料把 étendue 守恒讲明白，并举一个例子说明为什么亮斑不能靠透镜无限放大。
- 20 次重复测量的标准差计算正确。
- 能说出至少 5 个常见激光波长及其用途。

## 常见陷阱

- 一开始就买一堆元件，结果不知道用它们测什么。
- 忽略"角度"的量纲（rad 是无量纲的，这个事实后面会非常有用来做小角近似）。
- 把"相对测量"当成"绝对测量"（相机像素值不是辐照度）。

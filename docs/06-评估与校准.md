# 06 评估与校准

> 长期项目会经历"感觉在进步"和"其实在漂移"两种状态的混淆。这份文档是唯一的裁判。

## 1. 四种合法证据

任何"我进步了"的声明，必须落到以下之一：

| 证据类型 | 具体形式 | 反例（不算） |
| --- | --- | --- |
| 预测 | 先写下预测值，再做实验，对上了 | 做完实验后说"我早就知道会这样" |
| 设计 | 给出满足指标的具体方案 + 选型理由 | 说"用软件优化一下就行" |
| 排障 | 定位并修好真实故障，能解释根因 | 换了个元件碰巧好了却不知原因 |
| 教学 | 讲清楚并让对方提出正确的问题 | 自己讲了一遍但没被追问 |

## 2. 阶段校准实验（Capstone）

每个阶段结束时，完成一个闭卷且定量的验收实验。这些不是练习，是考试。

| 阶段 | 校准实验 | 及格线 |
| --- | --- | --- |
| S0 | 用摄像头测量一个未知光源的相对光谱或照度分布 | 与理论/规格偏差 < 20%，有误差预算 |
| S1 | 设计并搭建一个望远镜或成像系统，实测焦距、放大率、视场、像差 | 实测与设计值偏差 < 5%，能解释残差 |
| S2 | 迈克尔逊干涉仪测波长 + 用刀口法测 PSF 宽度 | 波长偏差 < 3%，PSF 与衍射极限吻合 |
| S3 | 搭建偏振测量装置，测出样品 Mueller 矩阵 | 与已知样品吻合，能解释退偏 |
| S4 | 搭建激光器或倍频装置，测出阈值与转换效率 | 阈值预测与实测同量级（±30%），效率曲线合理 |
| S5 | 单光子/符合计数或散斑计量实验 | 能测出二阶相干度并正确解释 |
| S6 | 独立完成一件装置并达到公开指标 | 有完整的设计—搭建—标定—报告链条 |

## 3. 半年校准流程（每年 6 月、12 月，约 2 小时）

1. **闭卷推导**：从当前阶段的 5 个核心公式里随机抽 2 个，白纸推导，不看笔记。
2. **能力打分**：更新 `04-能力地图.md` 的两张表。只允许上调有实验或笔记证据的项。
3. **证据清单**：列出这半年里有新东西产出的实验、仿真、作品，数一数。
4. **失效分析**：这半年哪些笔记是错的、被你自己推翻的？（一个都没有反而是危险信号）
5. **前置条件复核**：时间、预算、空间、健康、家人态度有没有变化。
6. **下一阶段选择**：按路线图推进，或按兴趣调整纵深方向。

## 4. 年度检查（每年 12 月，约半天）

- 今年"拿在手上"的东西是什么？没有的话，明年强制至少一件。
- 今年最贵的一次错误是什么？学到了什么？
- 有没有任何一项能力达到 3 级（实战线）？没有的话，是不是节奏档位设错了？
- 重读 `00-项目章程.md`，是否有条款需要修改？
- 更新下一年的主题与预算。

## 5. 危险信号清单

出现以下情况时，停下来做一次校准：

- 连续 3 周只有输入（看书、看视频）没有输出。
- 笔记数量在涨，但笔记里的"验证实验"栏全是空的。
- 半年内没有一次"预测—验证"闭环。
- 买的器材数量超过做过的实验数量。
- 开始频繁更换学习方向或收藏新的书单。

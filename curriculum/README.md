# 课程体系

## 每个阶段文件的固定结构

| 小节 | 作用 |
| --- | --- |
| 阶段目标 | 学完你能做什么（用能力描述，不用知识点描述） |
| 核心问题 | 这一阶段真正要回答的 3–5 个问题 |
| 理论主线 | 主题清单 + 书目章节 |
| 必推公式 | 必须能闭卷推出来的东西 |
| 实验 | 动手清单，每项有可测的产出 |
| 仿真 | 计算轨道任务 |
| 阶段作品 | 阶段结束时留下的实物或文档 |
| 验收标准 | 及格线（定量） |
| 常见陷阱 | 前人踩过的坑 |

## 阶段的先后与依赖

```text
S0 地基
 └─> S1 几何光学与成像 ──> S2 波动光学与傅里叶光学
                              ├─> S3 电磁光学与偏振 ──> S4 激光与光物质
                              │                          └─> S5 量子与统计光学
                              └─> S6 专题纵深（长期并行）
```

严格必须的顺序只有：S0 → S1/S2 的核心概念。之后各支可以按兴趣交叉推进，
但 S3 的偏振和 S2 的相干性是 S4/S5 的前提，不要跳过。

## 关于教材的一个建议

**主线教材只选一本，其余作为参考。** 同时读三本书是长期项目最隐蔽的杀手。
默认建议：

- 中文主线：赵凯华《新概念物理教程·光学》 + 郁道银《工程光学》
- 英文主线：Hecht《Optics》（本科级）+ Saleh & Teich《Fundamentals of Photonics》（专业级）
- 工具书：Smith《Modern Optical Engineering》、Bass《Handbook of Optics》

完整书单与获取方式见 `../resources/书目与资源.md`。

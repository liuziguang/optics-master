# S6 专题与前沿

**时间：长期，与 S4/S5 并行**。这里不是"必须学完"的清单，而是"可以深入的方向菜单"。选 2–3 个深耕，其余保持了解。

## 选题原则

1. 选一个能和你已有的实验平台复用的方向。
2. 选一个"有公开指标可以对比"的方向（否则你无法客观评估）。
3. 选一个你真心好奇的，而不是"看起来很高级"的。

---

## 方向 A：光学设计与镜头

| 项 | 内容 |
| --- | --- |
| 核心内容 | 像差理论、优化算法、公差分析、杂散光分析、变焦与远心系统 |
| 工具 | Zemax OpticStudio（学生版）、OSLO、WinLens3D、`rayoptics` |
| 书目 | Smith《Modern Optical Engineering》、Geary《Introduction to Lens Design》、Kingslake《Lens Design Fundamentals》、郁道银《工程光学》 |
| 作品 | 设计并实测一支显微物镜或远摄组，MTF 实测与设计对比 |
| 验收 | 设计值 vs 实测 MTF 偏差可解释；能做公差敏感性分析 |

## 方向 B：干涉计量与精密测量

| 项 | 内容 |
| --- | --- |
| 核心内容 | 干涉仪架构、相位解调（相移法/傅里叶法）、误差分离、亚纳米测量 |
| 工具 | 自建斐索/泰曼—格林干涉仪、压电位移台、相机、相位解包算法 |
| 书目 | Malacara《Optical Shop Testing》、Gasvik《Optical Metrology》、Yoshizawa《Handbook of Optical Metrology》 |
| 作品 | 一台能测面形或位移的干涉仪，分辨率到 nm 量级 |
| 验收 | 能测出一块镜面的 PV/RMS 面形，与干涉仪对比 |

| 项 | 内容 |

## 从"菜单"到"选题"的决策方法

用四个问题打分（每个 1–5 分）：

1. **好奇心**：不看任何理由，我就是想做它。
2. **复用性**：能复用我已有的器材和技能吗？
3. **可验收**：有客观指标吗？
4. **可持续**：这个方向能让我做 5 年而不腻吗？

总分最高的选 2 个，一个主攻一个副攻。**不要超过两个。**

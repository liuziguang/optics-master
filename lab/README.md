# 实验室

这里存放所有**动手**的东西：实验记录、装置照片、数据、光路图、标定结果。

## 目录约定

```text
lab/
├─ README.md
├─ 仪器与元件清单.md            # 我有什么、多少钱、放在哪
├─ 实验索引.md                  # 做过的实验一览（进度感来源）
├─ 001-测透镜焦距/
│   ├─ README.md               # 实验记录正文
│   ├─ setup.jpg               # 装置照片
│   ├─ optical-path.png        # 光路图（或用 ASCII/TikZ）
│   └─ analysis.ipynb          # 数据处理
└─ 002-迈克尔逊干涉仪/
```

编号三位数递增，永不重排。**失败和废弃的实验也保留**，标上状态。

## 实验的四个阶段（缺一不可）

| 阶段 | 动作 | 产出 |
| --- | --- | --- |
| 计划 | 写目的、假设、预测值、器材、步骤、安全事项 | 实验设计（在做之前写完！） |
| 执行 | 搭、测、拍照、记录异常 | 原始数据 + 照片 |
| 分析 | 处理数据、与理论对比、算不确定度 | 图表 + 结论 |
| 收尾 | 写"下次怎么做更好"、归档、清理工位 | 更新的实验记录 |

**最重要的规则：预测必须写在测量之前。** 这是把实验变成学习的唯一机制。

## 实验状态标记

| 标记 | 含义 |
| --- | --- |
| 计划中 | 只写了设计 |
| 进行中 | 搭了一半 |
| 已完成 | 有结论，有数据 |
| 卡住 | 记录了卡在哪，等待解决 |
| 放弃 | 记录为什么放弃（也是数据） |

## 安全

任何涉及激光的实验，开始前必须确认：

1. 波长与功率已知
2. 防护镜匹配该波长与功率
3. 光束终端有挡光板
4. 光路不在视平线上
5. 无人看管时关闭

详见 `../docs/05-运行手册.md` 第 8 节。

# 13 岗位样本库

> **这是什么**：一个**滚动累积**的岗位样本库。用户每发来一张岗位截图，
> 这里就加一条结构化记录，并更新累计统计。
>
> **和 `12-光学岗位要求与技能表.md` 的分工**：
> `12` 是两次**一次性抓取**的快照（英文 22 份企业 JD ＋ 中文 197 个院所岗位）；
> `13` 是**长期涓流**——用户主动挑出来的、他觉得有兴趣的岗位。
> 前者的价值是覆盖面，后者的价值是**兴趣指向**：他挑了哪一条，本身就是信息。
>
> 攒到 30 条以上时，把这里的统计并回 `12` 的第 11 节。

## 收录流程

| 步骤 | 谁做 | 内容 |
| --- | --- | --- |
| 1 | 用户 | 在对话里发截图（可多张），必要时补一句公司／岗位名 |
| 2 | Codex | 存进 `../inbox/jobs/YYYY-MM-DD-公司-岗位.png`（该目录不进 Git） |
| 3 | Codex | 读图，抽取下面的字段 |
| 4 | Codex | 追加一条记录到本文档，更新累计统计 |
| 5 | Codex | 回一句：这家的要求本项目覆盖了没有、缺口在哪 |

**编号规则**：`J-001`、`J-002`……连续编号，不重排、不删除。
看不清楚的字段写"截图不清"，不猜。
明显不是光学方向的标 `[非光学]`。

### J-001 · Lightmatter · Senior Laser & SOA Characterization Engineer

> **示例条目**（来自 `12` 第一轮抓取的企业岗位，不是用户提供的截图），
> 用来固化格式。从 J-003 起才应该是用户发来的截图。

| 项 | 内容 |
| --- | --- |
| 来源 | Lightmatter 招聘板（Greenhouse） |
| 地点 | Mountain View, CA |
| 性质 | 社招（资深） |
| 学历 | 博士或硕士，电子工程／物理／应用物理／光子学／光学 |
| 经验 | 5 年以上半导体激光器、SOA、光子或光器件**表征**的动手经验 |
| 核心知识 | 半导体激光物理、光学增益、载流子动力学、**速率方程**、热效应、反馈敏感性、**线宽**、**RIN**、光学噪声机制 |
| 必测指标 | 阈值电流、斜率效率、**电光转换效率（wall-plug）**、LIV 曲线、边模抑制比 SMSR、RIN、线宽、波长调谐、光谱、功率稳定性、波长稳定性 |
| 工具 | 光学与电光实验室测量（未指定软件） |
| 主要职责 | 做测量、出数据与结论、给跨职能团队写评审与建议 |

**本项目对应**：这条几乎是为本项目的 G1 到 G3 写的。
**阈值电流 / 斜率效率 / LIV** → G1；**波长稳定性 / 温漂** → G2；
**线宽 / RIN / 相位噪声** → G3；**速率方程** → S4。
`docs/07-北极星-极限光源.md` 第 4 节的每一代指标几乎都能在这条 JD 里找到对应词。

**值得记的一句**：它把「给跨职能团队写评审与建议」和「会测 RIN」并列写进要求——
**写报告在这类岗位里是和测量能力平权的**，不是可选项。

### J-002 · PsiQuantum · Silicon Photonics Engineer

> **示例条目**（同上，来自第一轮抓取）。

| 项 | 内容 |
| --- | --- |
| 来源 | PsiQuantum 招聘板（Greenhouse） |
| 地点 | Palo Alto, CA |
| 性质 | 社招 |
| 学历 | 博士或同等学力，电子工程或物理 |
| 经验 | 5 年集成光子学相关的工作或研究经历 |
| 核心能力 | 面向光子器件设计与性能评估的**计算与分析能力**；光子器件的性能指标与**测试方法** |
| 工具 | Lumerical 仿真套件；IPKISS 或 **gdsfactory** 做版图；**Python** 做科学计算与数据分析 |
| 主要职责 | 提出、开发并实施纠正措施（对应良率／失效分析流程） |

**本项目对应**：**S6 方向的岗位**，不是 G1 到 G5 的主线，但它印证了两件事——
（1）**仿真与版图是独立技能**，不是"顺便会一点"；
（2）**Python 被明确写成工作语言**，和 `12` 第 5.4 节"唯一跨岗位通用的工具"对上了。

**值得记的一句**：这条把工具名写得很具体（Lumerical／IPKISS／gdsfactory），
说明**在这类岗位上"会用哪个软件"是可以被考核的硬指标**——
而这一点对本项目不构成压力，因为你的主线不在硅光。

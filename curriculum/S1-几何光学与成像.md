# S1 几何光学与成像

**建议时长：3–5 个月**

## 阶段目标

学完你能：给定物距和元件，算出像的位置、大小、方向；判断一个成像系统的视场、孔径与相对照度；识别并定量分析主要像差；手工设计一个二至三片式系统并做出实物验证。

## 核心问题

1. 光线模型在什么条件下成立？什么时候它一定会失灵？
2. 一个"理想成像"系统需要哪些条件？现实中的偏离叫什么？
3. 为什么大口径的镜头更难做？
4. 视场和孔径哪一个在限制我的系统？

## 必推公式

- 近轴折射成像公式与放大率
- 两元件系统矩阵与等效焦距
- 主平面位置公式
- F 数与数值孔径的关系
- 景深计算公式
- 三级像差的波前函数形式（能写出即可，不必完整推导）

## 实验

| 实验 | 产出 | 及格线 |
| --- | --- | --- |
| 三种方法测透镜焦距（物像法、放大率法、自准直法） | 焦距报告 | 三法互相偏差 < 3% |
| 用刀口法（Foucault test）观察球差 | 刀口图像序列 | 能定性解释掩蔽方向与像差符号 |
| 白光聚焦观察色差 | 图像 | 能量化焦点偏移随波长的变化 |
| 拆解并分析一支现成镜头（老镜头/放大镜） | 结构图 + 元件数 + 估计焦距 | 能画出等效光路 |
| 用两个凸透镜搭开普勒望远镜 | 实物 | 实测放大率与理论偏差 < 10% |
| 搭伽利略望远镜并对比 | 对比记录 | 能解释视场与正倒像差异 |
| 用光阑改变孔径，观察像质与照度的权衡 | 数据表 | 能画出像差随孔径的变化趋势 |
| 测量一支镜头的视场与渐晕 | 曲线 | 能解释渐晕来源 |

## 仿真

- 用 Python 写一个球面折射的光线追迹器（含球差），与解析三级像差对比。
- 用 `rayoptics` 或 OSLO EDU 建立一个两片式消色差物镜，看赛德尔像差表。
- 画一组无量纲化的"像差随孔径/视场变化"的曲线图。
- **Zemax OpticStudio**：见 `../docs/14-软件学习路线.md`。**本阶段后半段开始用**，
  验收产出是设计一个双胶合消色差物镜，MTF 达标且能解释每个面在做什么。

## 阶段作品

**一台自制开普勒或伽利略望远镜**（或用现成透镜组装），附一份包含放大率、视场、像差观察与改进建议的报告。

## 验收标准

- 拿到任意两片透镜，能在 10 分钟内估算系统焦距与主平面位置。
- 能解释为什么单透镜无法同时消球差和色差。
- 能用光线追迹程序复现并解释刀口法看到的图样。
- 做的望远镜能实际看清楚远处的字。

## 常见陷阱

- 符号约定不统一，导致公式用错（**第一件事就是选定并写下自己的符号约定**）。
- 把 F 数和数值孔径混为一谈（小 F 数 = 大 NA = 高分辨率 = 浅景深，这四件事必须一次性串起来）。
- 用"理想薄透镜"思维理解厚透镜系统，主平面位置完全错。
- 忽略波长，选了"能聚焦"但色差严重的方案。

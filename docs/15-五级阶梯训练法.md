# 15 五级阶梯训练法（光学版）

> **移植自** `D:\Software_Prep\00_总纲\04_独立写出训练法.md`（2026-09-29 用户要求）。
> 原版用来练"空白纸写代码"，这里改成练**"空白纸写推导"**。

## 一、核心原理

**同一个推导，反复推，但每次的提示比上次少一点。**

不是换新内容。是同一个推导，从"照着抄"一路走到"什么都不给也能推出来"。

再加上**间隔重复**：当天推出来不算数，**第二天、第四天还能推出来，才算真的会了**。

## 二、五级阶梯

每一级**只改一件事**：给你多少提示。

| 级 | 你手上有什么 | 通过标准 | 状态 |
| :---: | --- | --- | :---: |
| **L1 看着抄** | 完整推导，每一步都写着 | 抄完，每一步都能说出在干什么 | |
| **L2 看中文步骤** | 5 到 7 句中文，**没有任何公式** | 照着中文把推导写出来，结论对 | |
| **L3 只看骨架** | 公式骨架 ＋ 几个空 | 把空填上，结论对 | |
| **L4 空白纸** | 什么都没有 | 一次推出来，结论对 | |
| **L5 隔天重现** | 什么都没有 | 第二天、第四天各推一次，都对 | |

**只有走到 L5，才算"能独立推出来"。** L1 到 L3 只是路上的台阶。

## 三、为什么要一级一级来（本节最关键）

"推不出来"其实是好几件不同的事混在一起：

```
推不出来，可能是：
  ① 不知道下一步该干什么          → L2 治这个（中文步骤告诉你"干什么"）
  ② 知道干什么，但不知道用哪条规则  → L3 治这个（骨架告诉你"长什么样"）
  ③ 都知道，但手生、写不快        → L4 / L5 治这个（练手感）
```

**大部分人以为自己是 ③，其实卡在 ① 或 ②。**

### 你自己的诊断（09-25 到 09-28 的实际记录）

| 你犯过的错 | 属于哪一类 |
| --- | --- |
| C04：`arccos(3/5)` 写成 63° | ① 或 ② —— 不是手生，是不知道该干什么 |
| C04：`−2i` 的模写成 `−2` | ② —— **规则不熟**（模必须非负） |
| C06：旋转方向写成顺时针 | ② —— **规则不熟**（正号逆时针） |
| C09：取模时漏掉绝对值 | ② —— **和 C04 是同一条规则** |

**四次里至少三次是 ② 类。** 也就是说：**你缺的不是"多做几道题"，而是把少数几条规则练到不可能错。**

**L2 和 L3 正是干这个的。**

## 四、每一级都必须做的事：算出一个数

**推完立刻验算，不验等于没推。**

光学和编程不一样——代码能跑，推导不能。所以每一级的"通过标准"都是**代一个值进去，看结果对不对**：

| 验算方式 | 例子 |
| --- | --- |
| 代特殊值 | `Δφ = 0` 应得最亮；`Δφ = π` 应得全黑 |
| 代边界值 | `x = 0`、`θ = 0`、`ΔL = 0` |
| 与已知结论对照 | `ΔL = λ/2` 应该相消（实验上知道的事） |
| **与自己推过的另一条公式交叉验证** | 用 C09 的公式去查 C10 的结果 |

**对不上就停在那一级，不要往上跳。**

## 五、什么值得走五级

不是每张卡都要五级。**只用在"核心推导"上。**

| 值得 | 不值得 |
| --- | --- |
| 双光束干涉合振幅（C09） | 某个特殊值的计算 |
| `Δφ` 与 `ΔL` 的关系（C10） | 查一个常数 |
| 迈克尔逊条纹移动（C11） | 某条软件菜单的位置 |
| 菲涅尔公式（S3） | |
| 薄膜传输矩阵（S3） | |
| 激光速率方程（S4） | |

**判断标准只有一句：这个东西以后会不会反复用到？** 会，就值得。

## 七、一句话

> **把同一个推导推五遍，比推五个新推导有用。**
>
> 因为你要的不是"我见过这个公式"，而是"我的手能自动把它推出来"。

## 六个空

```
合波 = A·e^(iΦ)  +  ___①___                          ← 第二列写成什么

     = A·e^(iΦ)  +  A·e^(iΦ) · ___②___              ← 拆出来的第二个因子

     = A·e^(iΦ) · ( ___③___ )                       ← 提公因子后的括号

     = A·e^(iΦ) · e^(iΔφ/2) · ( ___④___ )           ← 再提一次后的括号

     = A·e^(iΦ) · e^(iΔφ/2) · ___⑤___               ← 认出括号是什么

合振幅 = | 合波 | = ___⑥___                          ← 取模
```

---

## 三个提示（卡住了再按顺序看）

1. **①** 只是把 `Φ + Δφ` 写进指数而已，原封不动
2. **③** 两项共同的部分只有一块，提出来之后剩下的是 `1` 加一个指数
3. **⑤** 括号长得像 `e^(−iθ) + e^(iθ)`，其中 `θ = Δφ/2`；它是**余弦**的 2 倍

> **⑥ 没有提示。** 那是你自己要负责的地方——想想模能不能是负的。

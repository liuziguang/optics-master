# 开源项目与社区

> 原则：**先用现成的，别重造轮子。** 你的时间应该花在光源本身，
> 而不是花在重写一个已有的光线追迹器上。
>
> 项目与星数核实于 2026-09-21（星数会变，仅用于判断成熟度）。

## 1. 使用原则

1. **先找现成的，再考虑自己写。** 只有在需要理解内部机理时才重写一遍。
2. **用了别人的东西要记录**：项目名、版本、许可证，写进实验记录的"工具"一栏。
3. **看许可证再改。** 见第 11 节。
4. **改造优先于重写**：能提 issue、发 PR，就比另起一个仓库好。

## 11. 许可证注意事项

用别人的项目前，先看它的 LICENSE 属于哪一类：

| 类型 | 例子 | 你能做什么 |
| --- | --- | --- |
| 宽松（MIT / BSD / Apache） | pyvisa、prysm、gdstk | 随便用、改、商用，保留声明即可 |
| 传染性（GPL） | 部分实验室软件 | 改动后分发必须以同样许可证开源 |
| 硬件专用（CERN-OHL） | 部分开源硬件 | 有专门的硬件开源条款，注意"开源"的具体含义 |
| 文档类（CC BY / CC BY-SA） | 多数教材笔记 | BY-SA 有"相同方式共享"要求 |

**本项目自己的授权**：代码 MIT、文档 CC BY 4.0（见仓库根目录）。
你引用别人的代码时，把来源与许可证写进对应实验记录的"工具"一栏。

## 12. 映射：哪些开源项目对应哪一代光源

| 代 | 主要依赖的开源项目 |
| --- | --- |
| G0 可控激光光源 | ray-optics、lightpipes、spectral-workbench |
| G1 低噪声光源 | pyvisa、Qcodes/PyMoDAQ、Red Pitaya |
| G2 温控与单模 | PyMoDAQ、pyvisa（控温与波长监测） |
| G3 窄线宽 | pyrpl、specutils（线宽与漂移分析） |
| G4 原子锁定 | **pyrpl、RedPitaya-Lockbox**、Steck 数据、SAS 实验讲义 |
| G5 量子光源 | labscript-suite、Qcodes、符合计数自制固件 |
| G6 极限挑战 | 以上全部，加上你要新写的部分 |

## 13. 一条建议

**不要一开始就 clone 二十个仓库。** 按需引入：每个阶段开始前，
从这份清单里挑 2 到 3 个真正要用的装好，其余的等到需要时再说。

已经有太多人把"配置环境"当成了项目本身。

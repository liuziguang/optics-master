## 2026-09-21 · 本地书库迁入项目

**做了什么**

- 把 150 份精选资料（约 2.4 GB）复制到 `D:\Optics_Master\library\`，
  按 12 类分库，并使用与项目内一致的目录名。
- `.gitignore` 增加 `library/*` 与 `!library/README.md`：
  **只有索引 README 会进仓库，所有 PDF 永远留在本机。**
- 新增 `library/README.md`：说明为什么不在 Git 里、目录结构、使用规则、
  以及每次新增文件后的自检命令。
- `resources/本地书库索引.md` 更新为项目内路径。

**为什么这样做**

本仓库是公开的。把受版权保护的书籍推上去等于公开传播，既不合法，
也会让仓库体积涨到无法克隆。所以采用"本地可用、Git 排除"的方案：
在本项目内，但永不上传。

**验证**

- `git check-ignore` 确认 `library/` 下的 PDF 全部被忽略。
- `git status --short` 中 `library/` 只出现 README.md。

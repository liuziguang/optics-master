# 02 前置条件问卷

> `01-前提条件.md` 是结论表，这里是**问题本身**，附上"为什么问"。
> 不需要一次答完。按 A→F 顺序，一次答 5–10 题即可，答完直接写进档案。

## A. 基础与背景

| # | 问题 | 为什么问 |
| --- | --- | --- |
| A1 | 微积分/微分方程/线性代数/复变函数，各自是"熟练 / 学过忘了 / 没学过"？ | 决定是否需要先补数学，还是直接上波动光学 |
| A2 | 麦克斯韦方程组你现在的状态是"能推 / 能用 / 只记得名字"？ | 决定 S3 电磁光学是主线还是补课 |
| A3 | 你上一次认真做题（不是看视频）是什么时候？ | 判断"学习肌肉"的现状 |
| A4 | 编程：能独立写 100 行 Python 并调通吗？会用 numpy/matplotlib 吗？ | 决定仿真轨道是立即启用还是要先学工具 |
| A5 | 有没有硬件/电子动手经验（焊过电路、装过机器、做过东西）？ | 决定实践轨道的起点难度 |
| A6 | 英语原版教材对你来说是障碍还是选择？ | 决定用中译本还是原版清单 |
| A7 | 你更擅长"从公式理解"还是"从图像/直觉理解"？ | 决定每个主题的第一入口形式 |

## B. 时间与节奏

| # | 问题 | 为什么问 |
| --- | --- | --- |
| B1 | 一周里哪几个时段是**几乎不会被抢走**的？ | 这是唯一能承载长期项目的资源 |
| B2 | 出差/加班频率如何？最长会断多久？ | 设计"断线恢复协议" |
| B3 | 你更接受"每天 20 分钟"还是"每周两晚各 2 小时"？ | 决定会话类型的主结构 |
| B4 | 你能接受连续几个月只有微小进步吗？ | 长期项目的心理门槛 |
| B5 | 你希望有外部提醒/打卡吗，还是讨厌被 push？ | 决定是否设置自动化提醒 |

## C. 空间与设备

| # | 问题 | 为什么问 |
| --- | --- | --- |
| C1 | 有没有一块可以长期不收拾的桌面或房间？ | 光路实验不能每次拆 |
| C2 | 有没有能遮光的地方 / 晚上是否方便关灯？ | 决定干涉、弱光实验的可行性 |
| C3 | 楼板振动情况（附近有地铁、施工、重车吗）？ | 决定干涉测量能做到什么精度 |
| C4 | 现有器材清单（哪怕是激光笔、放大镜、旧相机镜头）？ | 很多入门实验可以用现成物 |
| C5 | 有没有 3D 打印机 / 电钻 / 手工具？ | 决定"自制夹具"的路径 |
| C6 | 家里有没有人/宠物可能被激光伤到？电源与高压条件是怎样的？ | 安全底线 |

## D. 预算

| # | 问题 | 为什么问 |
| --- | --- | --- |
| D1 | 启动期你能接受的总额是多少？ | 决定是"淘宝入门套件"还是"Thorlabs 正经平台" |
| D2 | 每年常规投入上限？ | 决定器材清单的更新速度 |
| D3 | 是否愿意买二手（显微镜、激光器、光学平台二手很划算）？ | 同样预算能翻 3 倍效能 |
| D4 | 是否接受"先用便宜货学，坏了再换好的"？ | 新手很容易把元件搞坏 |
| D5 | 有没有一直想买但没买的器材（说明你的真实兴趣指向）？ | 兴趣是最强约束 |

## E. 目标与动机

| # | 问题 | 为什么问 |
| --- | --- | --- |
| E1 | 如果十年后只能留下**一件**东西代表你的光学水平，你希望是什么？ | 北极星 |
| E2 | 三个你最想亲手做出来的东西是什么？ | 反推需要的能力 |
| E3 | 你对哪类光最着迷：成像 / 激光 / 量子 / 光谱 / 天文 / 视觉 / 材料？ | 决定纵深方向 |
| E4 | 你是想"懂原理"还是想"能做出东西"，还是都要？ | 决定理论/实践的时间配比 |
| E5 | 你希望这件事是私人的还是被看见的？ | 决定输出轨道的强度 |
| E6 | 有没有一个具体的对比对象——你觉得"他那样就算大牛了"？ | 定义成功标准 |
| E7 | 为什么是"一生"，而不是"三年速成"？ | 检验动机的真实结构 |

## F. 约束与风险

| # | 问题 | 为什么问 |
| --- | --- | --- |
| F1 | 过去失败/烂尾的项目，共同的失败模式是什么？ | 这是最值钱的一条信息 |
| F2 | 视力和身体状态如何（长时间看激光/暗室是否有影响）？ | 安全与耐久 |
| F3 | 家人对"占空间、花钱、折腾"的态度？ | 最常见的隐性杀手 |
| F4 | 你能接受的"卡住"最长多久而不放弃？ | 设定恢复机制的阈值 |
| F5 | 有没有明确的截止期限（考试、比赛、工作需求）？ | 决定节奏的紧张度 |
| F6 | 如果一年后发现进步很慢，你会怎么反应？ | 提前写下应对剧本 |

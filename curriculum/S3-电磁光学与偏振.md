# S3 电磁光学与偏振

**建议时长：3–5 个月**

## 阶段目标

学完你能：从麦克斯韦方程组出发解释反射、折射、吸收与色散；熟练使用琼斯与斯托克斯形式处理偏振问题；设计并实测多层膜系；理解晶体光学中的双折射与相位匹配的前提。

## 核心问题

1. 光在界面上的行为（振幅、相位、偏振）由什么唯一决定？
2. 偏振态有多少种描述方式，各自适合什么问题？
3. 为什么薄膜能"凭空"让透射率从 96% 提到 99.9%？
4. 各向异性介质里"光线"还能用几何光学描述吗？

## 必推公式

- 由麦克斯韦方程组导出波动方程并给出光速
- 菲涅尔反射/透射系数（s 偏振与 p 偏振）
- 布儒斯特角条件
- 波片相位延迟公式（含波长依赖）
- 单层膜的反射率公式与四分之一波条件
- 多层膜的特征矩阵

## 实验

| 实验 | 产出 | 及格线 |
| --- | --- | --- |
| 用偏振片验证马吕斯定律 | 曲线 | 与 cos²θ 拟合吻合 |
| 用反射法测布儒斯特角，求折射率 | 折射率值 | 与标称值偏差 < 3% |
| 用波片 + 偏振片测相位延迟 | 延迟值 | 与标称 λ/4 偏差 < 10% |

| 用分光光度计或自制装置测一块镀膜镜的反射率曲线 | 反射率曲线 | 能识别出膜系类型 |

| 用椭偏思路测薄膜厚度（进阶） | 厚度值 | 与台阶仪或干涉法交叉验证 |

## 仿真

- 写菲涅尔公式计算器：给定 n₁、n₂、角度、波长，输出 Rs/Rp/Ts/Tp 曲线，并画布儒斯特角。
- 用传输矩阵法写一个多层膜计算器，设计一个 550 nm 增透膜和一个高反镜。
- 用 `tmm` 库交叉验证自己的实现。
- 画庞加莱球上的偏振态演化（如线偏振经波片后的轨迹）。
- **COMSOL Wave Optics**：见 `../docs/14-软件学习路线.md`。用同一个多层膜问题建模，
  **验收标准是 COMSOL 算出的反射率曲线与自己写的传输矩阵法结果重合**。
  这是第一次"仿真与解析解对照"的训练。

## 阶段作品

**一台自建偏振测量仪**（起偏器 + 样品 + 检偏器 + 探测器/相机 + 自动采集脚本），配一份穆勒矩阵测量报告。

## 验收标准

- 能解释"为什么反射光在布儒斯特角完全偏振"而不用查公式。
- 能判断一个未知光学元件是"相位延迟器"还是"旋光器"，并说明判据。
- 能设计出一个满足给定中心波长和带宽的带通滤光片膜系。
- 能解释克拉默斯—克勒尼希关系的物理含义（吸收必然伴随色散）。

## 常见陷阱

- 只记住琼斯矩阵公式，没建立"偏振是二维复矢量"的图像。
- 忘记波片的延迟量是波长相关的，在非设计波长上直接用。
- 把琼斯（完全偏振）与穆勒（含退偏）混用。
- 忽略应力双折射：镜架夹太紧会引入额外偏振效应，这在精密实验里非常常见。

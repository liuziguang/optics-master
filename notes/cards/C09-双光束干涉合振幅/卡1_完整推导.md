# 卡 1 · 完整推导（L1 · 第 1 遍用）

> **规则**：照着抄一遍。**每一步都要能说出"这一步在干什么"。**
> 抄完代三个值验算。
>
> 这一级不看速度，只看你有没有跟上每一步。

---

## 要推的东西

两列**同频**波，振幅都是 `A`，第二列比第一列**多一个相位差** `Δφ`。
问：合起来的振幅是多少？

---

## 推导（六步）

**第 0 步 · 把两列波写成复指数**

```
第一列：  A · e^(iΦ)
第二列：  A · e^(i(Φ+Δφ))
```

`Φ` 是第一列的相位，`Δφ` 是两列的相位差。
（用复指数而不用 `cos`，是因为相乘相加更方便——这是 C02 讲的。）

---

**第 1 步 · 相加**

```
合波 = A·e^(iΦ)  +  A·e^(i(Φ+Δφ))
```

---

**第 2 步 · 把第二个指数拆开**

用 C07 推过的规则（相位相加 → 指数相乘），反过来用：

```
e^(i(Φ+Δφ)) = e^(iΦ) · e^(iΔφ)
```

代回去：

```
合波 = A·e^(iΦ)  +  A·e^(iΦ)·e^(iΔφ)
```

---

**第 3 步 · 提公因子**

两项都有 `A·e^(iΦ)`，提出来：

```
合波 = A·e^(iΦ) · ( 1 + e^(iΔφ) )
```

---

**第 4 步 · 处理括号 —— 先给 `1` 换个写法**

关键技巧：`1` 也能写成指数。

```
1 = e^(iΔφ/2) · e^(−iΔφ/2)
```

为什么？因为指数上两个角**加起来是 0**，而 `e^0 = 1`。

用这个把括号里两项都写成「`e^(iΔφ/2)` 乘某个东西」：

```
1 + e^(iΔφ) = e^(iΔφ/2)·e^(−iΔφ/2) + e^(iΔφ/2)·e^(iΔφ/2)
            = e^(iΔφ/2) · ( e^(−iΔφ/2) + e^(iΔφ/2) )
```

---

**第 5 步 · 认括号 —— 反向欧拉公式**

括号里是 `e^(−iθ) + e^(iθ)`，令 `θ = Δφ/2`。

欧拉公式 `e^(iθ) = cosθ + i·sinθ` 反过来写就是：

```
cosθ = ( e^(iθ) + e^(−iθ) ) / 2
```

所以：

```
e^(−iΔφ/2) + e^(iΔφ/2) = 2·cos(Δφ/2)
```

代回去：

```
合波 = A·e^(iΦ) · e^(iΔφ/2) · 2cos(Δφ/2)
```

---

**第 6 步 · 取模**

合振幅 = 合波的**模**。

关键：`e^(i·随便什么)` 的模**永远是 1**（纯相位因子）。
所以模只由前面的实数决定：

```
合振幅 = | 2A·cos(Δφ/2) | = 2A · |cos(Δφ/2)|
```

**绝对值不能丢。** `cos(Δφ/2)` 可以是负的（比如 `Δφ = 3π/2` 时），而模不能为负。

---

## 抄完立刻验算

| 代什么 | 算一下 | 应该得到 |
| --- | --- | --- |
| `Δφ = 0` | `2A·|cos(0)|` | `2A` |
| `Δφ = π` | `2A·|cos(π/2)|` | `0` |
| `Δφ = 2π` | `2A·|cos(π)|` | `2A` |

**三个都对，L1 通过。** 然后去 [卡2](卡2_中文步骤.md)。

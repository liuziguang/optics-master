# 01 设计前提

> 这份文档记录**影响设计决策的约束类型**，以及由它们推导出的方案。
> 具体的个人数值（时间量、预算、身份、动机、心理记录）不在这里，保存在非公开目录中。
>
> 这样写有两个好处：公开的那部分可以被任何处境相似的人直接复用，
> 私人的那部分可以随时改动而不影响方法论。

最后更新：2026-09-21

## A. 约束类型

| 约束 | 形态 | 由此产生的设计要求 |
| --- | --- | --- |
| 时间总量 | 有限，属于业余投入 | 全部计划按"业余档"标定，不做职业级假设 |
| 时间分布 | 集中在固定的整块时段（周末），工作日不可用 | 周末双块结构；装置必须能跨周保存状态或完全拆装 |
| 时间连续性风险 | 任务跨度超过一天就容易积压 | **任务必须拆到单次可完成**；必须设每日检查点 |
| 学科基础 | 数学与物理学过已忘 | 增设 S-1 补课阶段，与光学并行而非串行 |
| 实验空间 | 无专用实验室，但有可占用房间 | 桌面工作站 + 光学暗箱；可做半固定布置，不必每次全拆 |
| 安全环境 | 可做到独立房间、关门实验 | 风险等级中等：省掉带锁箱体，但仍需防护镜与光束终端挡光 |
| 预算 | 有限且按月投入，接受二手 | 二手优先；先买测量、后买光源；不买大件 |
| 技能边界 | 编程与硬件电子另立项目，不在本项目内 | 本项目不设编程/电子学习目标，只用它们当工具 |
| 兴趣优先级 | 1 激光与光源，2 天文望远镜，3 量子光学 | 主线光源；天文为实质副线；量子光学为长期纵深 |
| 输出意愿 | 公开 + 外部检验 | 仓库分层，方法论公开、个人信息私有 |
| 头号风险 | **缺少日常监督导致中断即放弃** | 见 `11-监督机制.md`，这是全项目的最高优先级设计 |

## C. 本条设计里最反直觉的一点

大多数学习计划失败在"任务太大、检查太少"。

本项目把"缺少日常监督"当作头号风险来对抗，所以**所有任务都必须小到当天能完成，
且每天必须有一次记录**——哪怕记录的内容是"今天什么都没做"。

记录本身不是仪式，它是让中断可见的唯一手段。中断不可见，就会变成放弃。

详见 `11-监督机制.md`。

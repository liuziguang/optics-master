# 09 空间方案：没有固定实验室怎么办

> 已确认：没有专用实验室，但**可以安排一个独立房间**做实验（门可关、无人打扰）。
> 这比"完全没有空间"宽松得多——可以搭一个半固定的工作站，不必每次全拆。
>
> 这份文档给出的是"无专用实验室"条件下的最优布置。
> 即使将来有了独立房间，其中的暗箱与整板光路依然值得保留。

## 1. 空间约束推导出的五条设计规则

| 规则 | 含义 |
| --- | --- |
| **半固定** | 工作站可以长期摆着，但必须能一键进入"可收状态"（盖箱、断电） |
| **可移动** | 光路要能**整体搬走而不失调**（最重要的技巧，见第 3 节） |
| **可遮盖** | 暗箱既做遮光，也做防尘——敞开放置的光学元件是灰尘的头号受害者 |
| **小型化** | 光路口径压缩到 12.7 mm 元件级，光程压缩到 20 cm 以内 |
| **光纤化** | 能用光纤就走光纤；光纤可以卷成小圈，还能抗振动与气流 |

## 2. 核心装备：光学暗箱

一个带盖的收纳箱，内壁贴哑光黑绒布，就是一个**便携暗室 + 防尘柜 + 防风罩 + 减振壳**。

| 项 | 规格建议 | 价格 |
| --- | --- | --- |
| 收纳箱 | 60×40×30 cm 以上，带锁扣，塑料或铝合金 | ¥100–250 |
| 哑光黑绒布 / 植绒纸 | 贴内壁与内底 | ¥30–60 |
| 减振垫 | 箱底铺 2–3 cm 高密度海绵或橡胶垫 | ¥30 |
| 走线孔 | 侧壁开孔走电源与数据线（用挡光套筒封住） | — |
| 内部小平台 | 5 mm 钢板 20×20 cm，或 300×200 铝板 | ¥50–150 |

**收益**：遮光、防尘（光学元件最大的敌人）、防风（干涉稳定性的头号杀手）、
部分隔声与隔振、光学元件就地存放不用反复收纳。

即使你将来有了房间，这个箱子依然有用。

## 3. 关键技巧：整体可移动光路

传统光学实验的痛点：每次搭建都要重新对准，1 小时对准 + 20 分钟测量。

**解法**：把光路建在一块**刚性底板**上，而不是直接建在桌面上。

```
   [ 铝板或钢板 20×20 cm ]
        ├─ 激光器（带夹具）
        ├─ 透镜/光阑（迷你镜架）
        └─ 探测器（固定支架）
   整块板可以端着走，对准关系保持不变
```

| 优点 | 说明 |
| --- | --- |
| 免重新对准 | 板上的相对位置不变，只需重新固定板本身 |
| 快速切换 | 做多个实验 = 准备多块板 |
| 可堆叠收纳 | 板放进箱子，垂直叠放 |
| 稳定性更好 | 刚性一体板比分立镜架抗扰动得多 |

**配套要求**：所有元件必须有**定位标记**（用刀刻线或记号笔标位置），
并在板上贴一张照片或示意图。下次照图装回。

## 4. 光纤化：把光路从"桌面"变成"盒子"

对光源工程（见 `07-北极星-极限光源.md`）尤其合适：

| 自由空间做法 | 光纤化做法 | 空间收益 |
| --- | --- | --- |
| 1 m 长的准直光路 | 2 m 光纤跳线盘成 10 cm 圈 | 100 倍 |
| 分立镜片对准 | 光纤准直器 + 法兰 | 免对准 |
| 干涉仪 | 光纤迈克尔逊（2×2 耦合器） | 极大 |
| 分束与合束 | 光纤耦合器 | 极大 |

代价：光纤耦合本身需要对准，但**只需要做一次**，之后永久保持。
而且光纤耦合的效率测量本身就是一个很好的实验。

## 5. 桌面级底座方案（按预算选）

| 方案 | 做法 | 价格 | 适用 |
| --- | --- | --- | --- |
| A. 极简 | 5 mm 钢板 + 橡胶垫 + 磁吸/夹持底座 | ¥50–150 | 光源、探测器、电子学 |
| B. 标准 | 200×200 或 300×300 mm 铝合金面包板（M6 螺孔阵） | ¥150–500 | 大多数小型光路 |
| C. 加强 | 面包板 + 沙袋 + 海绵垫 | +¥50 | 干涉、弱信号 |
| D. 长期 | 二手小型光学平台（60×90 cm）放在房间里 | ¥2000–8000 | 有了可用房间后，值得提前考虑 |

**现在从 A/B 起步；有了独立房间后，D 可以比原计划提前（第 2 到 3 年）。**
一台小光学平台会显著改善干涉与稳频实验的稳定性，是光源工程最划算的一次性投入。

## 6. 哪些实验暂时不做

诚实的清单。列出来不是为了放弃，是为了**不要在错误的地方消耗热情**。

| 实验类型 | 原因 | 替代或时机 |
| --- | --- | --- |
| 需要 1 m 以上长光程的干涉仪 | 桌面放不下 | 光纤干涉仪；有平台后可做 |
| 大口径望远镜磨制（8 英寸以上） | 需要长期占用空间与脏活场地 | 先买成品望远镜做观测，磨镜留到有独立场地时 |
| 真空镀膜 | 需要真空设备与场地 | 购买成品镀膜元件 |
| 需要超净间的操作 | 灰尘控制不住 | 用暗箱 + 密封盒 |
| 高功率激光加工 | 安全空间不足 | 不做 |
| 需要长时间无人值守的稳定性测量 | 需要独立房间与断电保护 | 有房间后可以做，但必须做到"门可关、电可断、光有终点" |

## 7. 一个典型的周末流程

| 时间 | 动作 |
| --- | --- |
| 周六 0:00–0:15 | 搬出暗箱与底板，接通电源 |
| 周六 0:15–0:30 | 按图装回或直接使用（若底板未拆） |
| 周六 0:30–2:30 | 搭建 / 调整 / 观察 |
| 周六 2:30–3:00 | 记录、拍照、写下"下次从这里继续" |
| 周日 0:00–1:30 | 采集数据 / 重复测量 |
| 周日 1:30–2:00 | 收尾：整理数据、写结论、拆卸装箱 |

**周日的"收尾"是这套流程里最容易省掉、也最不能省掉的一步。**
没有收尾，下周六的你会从零开始。

## 8. 天文观测：空间约束的意外出路

你的兴趣里有天文望远镜。它恰好是**最不受室内空间限制**的方向：

- 设备可收纳，观测在户外（阳台、楼顶、郊区）；
- 不需要暗室（天空本来就是暗的）；
- 望远镜口径是唯一限制，而 6–8 英寸的成品镜完全可收纳；
- 观测数据可以上传到公开平台，直接构成**外部检验**（见 `10-外部检验与公开计划.md`）。

所以天文是你四个兴趣里，唯一能"绕开"空间约束的那一支。
建议它作为**并行副线**：天气好的周末观测，阴天做光源。

## 9. 安全环境

已确认实验可以安排在**独立房间、关门操作**。风险等级因此为中等，可以省掉带锁箱体。

但仍然要满足三条最低要求：

1. 实验房间的门可以关上，实验时无人进出。
2. 光束终端必须有挡光板，光路不指向门口、窗户或座位方向。
3. 3B/4 类激光必须戴匹配波长的防护镜；无人看管时断电、盖箱。

**不要因为环境可控就放松。** 意外发生时在场的是你自己。

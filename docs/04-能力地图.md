# 04 能力地图

> 路线图告诉你按什么顺序学，能力地图告诉你到底要长哪些肌肉。
> 用法：每 3 个月给自己每一项打分，看形状变没变。

## 0. 等级定义（0–5）

| 等级 | 含义 |
| --- | --- |
| 0 | 不知道有这个领域 |
| 1 | 知道概念，能看懂科普级解释 |
| 2 | 能读懂教材、能跟推导、能做题 |
| 3 | 能独立用这门知识设计并完成一次可定量验证的实验或仿真 |
| 4 | 能处理该领域内的非标准问题，能判断别人方案的对错，能解释异常 |
| 5 | 能做该领域的深度创新或达到同行求教的水平 |

等级 3 是实战线。本项目的验收标准，理论项与实践项都要求达到 3。

## 4. 快速自评技巧

不要凭感觉打分。用一个具体问题检验：

- **等级 2 检验**：给我推导一下双缝的强度分布，并说明哪些近似被用了。
- **等级 3 检验**：设计一个实验测出这块玻璃的折射率，精度 1%，给出误差预算。
- **等级 4 检验**：我的干涉条纹在缓慢漂移，列出 5 个可能原因并说明如何逐个排除。
- **等级 5 检验**：这个方法在我的条件下不适用，我给你一个替代方案和它的代价。

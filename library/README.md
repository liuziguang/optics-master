# 本地书库

> 位置：`D:\Optics_Master\library\`
> 内容：从 E 盘藏书（15587 份文档）中筛出的 150 份资料，约 2.4 GB，分 12 类。
> 逐本索引与"现在该读哪一本"见 `../resources/本地书库索引.md`。

## 为什么这些文件不在 Git 里

**这是有意的，不是遗漏。**

1. **版权**：这些是受版权保护的书籍与论文。本仓库是公开的，
   把它们推上去等于公开传播，既不合法也不负责任。
2. **体积**：2.4 GB 会把仓库变得无法克隆，也会拖慢每一次操作。

因此 `.gitignore` 里写了：

```gitignore
library/*
!library/README.md
```

**只有这个 README 会被提交，`library/` 下的所有 PDF 永远不会离开这台电脑。**

### 每次新增文件后自检

```powershell
cd D:\Optics_Master
git status --short          # library/ 下除了 README 不应出现任何文件
git check-ignore -v "library/某个文件.pdf"   # 应输出 .gitignore:42 那一行
```

**如果不小心推送了，唯一的补救是重写历史并强制推送**，越早代价越小。

## 使用规则

1. **每个阶段只开一本。** 库里有 28 本激光书，你只需要读 1 本。
2. **先查索引再打开文件。** `../resources/本地书库索引.md` 里每本都标了角色。
3. **工具书不读，只查。** Handbook of Optics 这类属于"卡住时翻一下"。
4. **不要让"我有了"变成"我读了"。** 收藏和理解之间隔着的是时间投入。

## 同步与备份

- 这个目录**不在 Git 里**，所以 `git clone` 拿不到它。
- 换电脑时需要单独拷贝，或用云盘同步（注意版权，不要公开分享链接）。
- 原始书籍仍在 E 盘原库中，本目录只是精选副本，可以随时删除重建。

## 维护

- 新书先放回 E 盘原库，确认要用再加进这里。
- 每半年复查一次：哪些书"在库里但一次没打开过"，考虑移出。

# 光学大师 / Optics Master

一个以十年为尺度经营的个人光学能力工程。

目标不是"学过光学"，而是成为那种人：给他一个光学现象，他能写出支配它的方程；给他一个需求，他能设计方案、做出来、测出来、把误差算清楚，并讲明白。

## 北极星：约束条件下的极限光源

**在明确的成本与体积上限内，让光源的某一项品质达到世界级水平，并且公开到别人能复现。**

这句话被拆成 11 个品质维度、3 个工作包和 6 代指标阶梯（G0 到 G6），
硬锚点是**把光源锁定到铷原子的 D2 线（780.24 nm）**——
一旦锁上，你的光源就和全世界任何一家计量院共享同一个频率标准。

详见 [docs/07-北极星-极限光源.md](docs/07-北极星-极限光源.md)。

## 这个仓库是什么

不是笔记堆，而是一个可运行的成长系统。四条轨道同时推进：

| 轨道 | 内容 | 位置 |
| --- | --- | --- |
| 理论 | 从几何光学到量子光学的主干知识 | `curriculum/` `notes/` |
| 实践 | 光路、器件、测量、制作 | `lab/` |
| 计算 | 仿真、数据、建模（工具，非学习目标） | `sim/` |
| 记录 | 日志、打卡、复盘、评估 | `journal/` `docs/` |

另有一个**不进 Git 的本地书库** `library/`（150 份书籍与论文，约 2.4 GB）。
它在本机可用，但因为受版权保护且体积大，已被 `.gitignore` 排除，
永远不会出现在这个公开仓库里。见 [library/README.md](library/README.md)。

## 三条不可违反的规则

1. **预测写在测量之前。** 没有测量的理解不算理解。
2. **任务必须小到单次能完成。** 今天完不成的，就不是任务，是项目，要继续拆。
3. **每天必须有检查点。** 哪怕内容是"无"。中断不可见，就会变成放弃。

第 3 条针对的是本项目的头号风险，完整机制见 [docs/11-监督机制.md](docs/11-监督机制.md)。

## 怎么用

1. 读 [docs/00-项目章程.md](docs/00-项目章程.md)，确认北极星与原则。
2. 读 [docs/01-前提条件.md](docs/01-前提条件.md)，理解方案为什么是这样设计的。
3. 按 [docs/05-运行手册.md](docs/05-运行手册.md) 的节律做事，不要临场决定"今天学什么"。
4. 每次动作都落盘：每天一行打卡，每次实验一份记录（模板在 `templates/`）。
5. 每 6 个月按 [docs/06-评估与校准.md](docs/06-评估与校准.md) 校准一次。

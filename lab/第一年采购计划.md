## 第 2 批：探测与测量（约 ¥1600）

**这是第一年最重要的一批。** 光源工程的调试有八成是电信号的调试。

| 物品 | 规格 | 价格 | 为什么关键 |
| --- | --- | --- | --- |
| 二手数字示波器 | 100 MHz，带 FFT，至少 2 通道 | ¥800 | 噪声、脉冲、锁相调试的必需品 |
| USB 光功率计 | µW 到 mW，带波长修正 | ¥350 | 光源工程的"体重秤" |
| 光电二极管与跨阻放大 | BPW34 等 + 运放 + 屏蔽盒（自制） | ¥200 | 测 RIN、测条纹、测微弱信号 |
| 单色 USB 相机 | 全局快门，可拆镜头，无红外滤镜 | ¥500 | 光束分析、干涉、散斑 |
| BNC 线材与转接 | 若干 | ¥150 | 被忽略但必须 |

**相机选购要点**：必须能拆镜头或用裸传感（去掉红外截止滤镜更好，便于测 780/850 nm）；
全局快门对条纹测量很重要；分辨率 1280×1024 以上够用；二手工业相机性价比最高。

| TEC 与温控元件 | TEC 片、热敏电阻、散热器、PID 驱动元件 | ¥250 |

**选 780 nm 而不是 650 nm 的理由**：780 nm 是铷原子 D₂ 线。
选它意味着你的 G1 光源从第一天起就在**通往 G4 原子锁定的路上**，而不是一条需要推倒重来的支路。

## 暂时不买（以及为什么）

| 物品 | 为什么先不买 |
| --- | --- |
| 3D 打印机 | 1000 到 3000 元够外协打印几百个零件，且不占你的空间 |
| 光学平台（60×90 cm 以上） | 你没有地方长期占着它 |
| 昂贵的"入门光学实验箱" | 里面的东西你用不上三分之二，且元件质量通常很差 |
| 大功率激光器 | 你的空间不具备安全条件 |
| SLM / SPAD / 光谱仪 | 属于第 3 到 5 年的器材，现在买会闲置 |
| 二手氦氖激光器 | 诱人但此刻优先级低于示波器与功率计，可放到第 4 批 |

## 二手验货要点

| 器材 | 验什么 |
| --- | --- |
| 示波器 | 自检信号是否正常，通道是否都工作，旋钮编码器是否跳变，探头是否配套 |
| 光功率计 | 是否有可用的探头、量程是否匹配、是否带波长修正、探头是否老化 |
| 工业相机 | 传感器有无坏点/霉斑、能否正常出图、驱动与 SDK 是否可得 |
| 激光二极管 | 是否带原装尾纤、是否被静电击穿、有无光斑照片 |
| 光学元件 | 有无霉斑、划痕、镀膜脱落（用强光侧照法看） |

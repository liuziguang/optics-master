# S4 激光与光物质相互作用

**建议时长：4–6 个月**

## 阶段目标

学完你能：用速率方程预测激光阈值与输出功率；设计、搭建、标定一个小型激光器或非线性光学装置；理解增益、损耗、模式竞争、调 Q 与锁模；能解释并计算二次谐波产生的效率与相位匹配条件。

## 核心问题

1. 激光为什么是"相干"的？这与"单色"是什么关系？
2. 阈值是什么时候出现的？由哪几个参数决定？
3. 怎么让激光从连续输出变成短脉冲？
4. 强光会怎样改变介质？什么时候这变成有用的工具？

## 必推公式

- 激光阈值条件（增益 = 损耗）
- 速率方程稳态解与输出功率
- 纵模间隔公式
- 高斯光束的 q 参数与 ABCD 变换
- 脉冲时间—带宽积
- 二次谐波效率与相干长度

## 仿真

- 数值求解三/四能级激光速率方程，画出输出功率随泵浦的变化。
- 用 ABCD 矩阵 + q 参数计算谐振腔的稳定区与光斑半径分布。
- 仿真高斯光束的传播与聚焦（含束腰位置）。
- 计算 SHG 的相位匹配角与温度带宽。
- **COMSOL 热—光耦合**：见 `../docs/14-软件学习路线.md`。
  把"电 → 热 → 机械变形 → 光学性能"这条链装进一个模型，用来解释 G2 的波长温漂。
  **这是本阶段与北极星结合最紧的一次仿真。**

## 阶段作品

**一台自建激光器或倍频装置**（例如：二极管泵浦的被动调 Q Nd:YAG 或 LBO 倍频绿光），配一份含阈值分析、效率曲线与安全规范的技术报告。

## 验收标准

- 拿到一组腔参数，能判断腔是否稳定并算出光斑尺寸。
- 能解释"为什么调 Q 能提高峰值功率但降低平均功率"。
- 能算出某晶体在给定波长下的相位匹配角，并用实验验证。
- 所有激光操作符合安全规范，有完整的防护记录。

## 常见陷阱

- 忽略激光二极管需要恒流驱动 + 防静电 + 温度控制，第一颗就烧掉。
- 把"相干性"和"单色性"当成同一件事。
- 在高功率光束路径上使用不合适的镀膜元件导致损伤。
- 忽视眼部安全，尤其在红外波段。
- 相位匹配算错一个符号，导致效率差几个数量级。

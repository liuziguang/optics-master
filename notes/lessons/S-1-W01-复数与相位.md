## §1 到 §2 复数从哪来（PDF 66 到 67）

**要点核对**

- 二次方程的判别式是负数时，实根不存在 → 必须引入新数
- 定义 `i` 满足 `i² = −1`
- 复数写成 `z = x + iy`，其中 `x` 是**实部**、`y` 是**虚部**
- **关键**：`x` 和 `y` 都是**实数**。虚部是 `y`，不是 `iy`

**一个观念上的更正**

`i` 不是"假想的数"。它是一个"另一个方向的单位"——和 `1` 平权。
把 `1` 看成"水平方向的单位"，`i` 就是"竖直方向的单位"。
复数 `x + iy` 就是这两条轴上的坐标。教材里"imaginary"这个词是历史包袱，不是数学事实。

## §3 复平面（精读，PDF 67 到 68）

**要点核对**

- 复数 `z = x + iy` 对应平面上一点 `(x, y)`：横轴是**实轴**，纵轴是**虚轴**
- 注意：纵轴上画的是 `y`，**不是 `iy`**
- 直角坐标与极坐标的关系：`x = r cosθ`，`y = r sinθ`
- 极坐标形式：`z = r (cosθ + i sinθ)`
- 因为 `cosθ + i sinθ = e^(iθ)`（这是 §9 要证的），所以也可以直接写 `z = r e^(iθ)`

**两个新名字**

- `r = |z| = √(x² + y²)`：**模**（也叫绝对值）
- `θ = arg z`：**辐角**

**【容易踩的坑】辐角不唯一**

`θ` 和 `θ + 2π`、`θ − 2π` 表示的是**同一个复数**。
所以"一个复数的相位是多少"这个问题本身没有唯一答案。
**物理上有意义的永远是相位差**，不是相位本身。这句话后面会在干涉里反复用到。

## §4 记号与弧度制（PDF 69 到 70）

**要点核对**

- 共轭：把虚部取反，记作 `z*` 或 `z̄`（以你书上为准）
- **一个重要恒等式**：`z · z* = |z|²`
- 教材专门用一节讲**弧度制**，理由是：`d/dx sin x = cos x` 这条公式**只在弧度制下成立**

**为什么这一节对光学特别重要**

相位里出现的 `ωt`、`kx` 全部是弧度。整个光学（以及所有波动问题）
都建立在"角度用弧度"这条约定上。用度数算相位，公式会全部失效。

> 记住这个换算：`180° = π 弧度`。你要经常在 `λ/2`、`π`、`180°` 之间来回切。

## §5 复代数（精读，PDF 71 到 75）

**要点核对**

- **加减**：实部与实部、虚部与虚部各自加减
- **乘法**：按普通代数展开，随时用 `i² = −1` 化简
- **除法**：分子分母同乘**分母的共轭**，把分母变成实数

**【自己推】** 把 `1/(1+i)` 化成 `x + iy` 的形式。
（提示：分母乘上自己的共轭 `1−i`；想一想为什么这样能让分母变成实数）

**本章最重要的一句话**

> **直角坐标形式适合加减，极坐标形式适合乘除。**

这不是修辞。后面你算干涉、算偏振、算光在晶体里的传播时，
每一次"把三角公式算到崩溃"的时刻，都是因为没有换成极坐标。

## §8 到 §9 欧拉公式（本周核心，PDF 80 到 83）

### §8 先定义 e 的 z 次方

实数上 `e^x` 有幂级数展开。教材把同一个级数直接推广到复数 `z`，
**用级数来定义** `e^z`。这一步是纯粹的推广，不需要新假设。

你只需要接受一件事：**级数对复数照样成立**。

### §9 把 `z = iθ` 代进去

**【自己推】** 这是本周最重要的一次推导，请一定在纸上推一遍：

1. 写出 `e^(iθ)` 的幂级数
2. 把每一项里的 `i` 的幂用 `i² = −1` 化简
3. 把结果分成**两组**：不含 `i` 的项、含 `i` 的项
4. 对照教材里 `sinθ` 和 `cosθ` 的幂级数（§9 开头给了），看这两组分别是什么

推完你会得到：

> **欧拉公式：`e^(iθ) = cosθ + i sinθ`**

**几个必须能脱口而出的特例**

| 输入 | 输出 | 几何含义 |
| --- | --- | --- |
| `θ = 0` | `e^(i0) = 1` | 不转 |
| `θ = π/2` | `e^(iπ/2) = i` | 逆时针转 90° |
| `θ = π` | `e^(iπ) = −1` | 转 180°＝反号 |
| `θ = −π/2` | `e^(−iπ/2) = −i` | 顺时针转 90° |
| `θ = 2π` | `e^(i2π) = 1` | 转一圈回到原处 |

**反向使用（把三角函数换成指数）**

```
cosθ = (e^(iθ) + e^(−iθ)) / 2
sinθ = (e^(iθ) − e^(−iθ)) / (2i)
```

这两条以后会反复出现——凡是遇到"三角函数的和差化积"，
换成指数就会变成简单的乘法。

**一个极其重要的性质**

`|e^(iθ)| = 1`，对任何实数 `θ` 都成立。

意思是：**纯相位因子的模是 1**。它只改变相位，不改变大小。
这句话是"相位不影响强度、只影响干涉"的全部根据。

## §10 乘除规则（PDF 84 到 86）

用 §9 的乘法规则，把两个复数都写成极坐标形式，立刻得到：

| 运算 | 结果 | 口诀 |
| --- | --- | --- |
| 乘法 | `r₁e^(iθ₁) · r₂e^(iθ₂) = r₁r₂ · e^(i(θ₁+θ₂))` | **模相乘，辐角相加** |
| 除法 | `r₁e^(iθ₁) / r₂e^(iθ₂) = (r₁/r₂) · e^(i(θ₁−θ₂))` | **模相除，辐角相减** |

**这两行是整章的落点。** 你只要记住"乘法＝辐角相加"，
后面所有"相位累加"的物理过程（光程、波片、延迟）都能一眼看穿。

**[连回卡片 C05]** 用这个规则心算 `(1+i)²`：
`1+i` 的模是 `√2`，辐角是 `π/4`；
平方之后模是 `2`，辐角是 `π/2`，所以结果是 `2i`。
和直接展开得到的一样——但极坐标形式一步就出来了。

## §16 应用：旋转（精读，PDF 96 到 99）

这一节把前面所有东西变成**图像**，是本周最该读的一节。

**要点核对**

- 教材的第一个习题就是：**乘以 `i` 等于把复数逆时针旋转 90°**
- 推广：**乘以 `e^(iφ)` 等于逆时针旋转 φ**，模不变
- `z = a·e^(iωt)` 描述一个匀速圆周运动；速度与加速度可以直接从复数乘法读出来
- 描述直线运动也可以用复数（习题 4 到 5），`z` 的实部与虚部各自是一条直线运动

**这就是光学的"相量"图像**

一个旋转的矢量，它的**实部**就是物理上真实的那个振动的量。
以后你看到"相量图"、"复振幅"、"相位矢量"，说的都是这件事。

> 记住这张图：**相位不是"公式里的一个角"，而是"矢量转到哪儿了"。**
> 干涉是矢量相加，相消是矢量反向。

## 为什么光学用复指数（这是卡片 C02 的出处）

> **先纠正一件事**：这个问题的答案**不在 Boas §1 到 §3 里**。
> Boas 是数学方法书，它只在 **PDF 第 67 页**用一句话提到"复数记号能简化振动问题的
> 建立与求解、并用于解微分方程"，**没有点破为什么**。
> 完整答案在光学教材里——本节末尾给了指针。
>
> 下面给两处对照，**结论留给你自己写**。

### 对照一：反复求导

| 用 cos | 用复指数（令 E = e^(iωt)） |
| --- | --- |
| d/dt cos(ωt) = −ω·sin(ωt) | dE/dt = iω·E |
| d²/dt² cos(ωt) = −ω²·cos(ωt) | d²E/dt² = (iω)²·E = −ω²·E |
| 中间要在 cos 和 sin 之间来回跳，还要盯符号 | 每一步都只是"乘一个常数" |

想一下：写波动方程、解麦克斯韦方程时，要对时间求几次导？
**哪一种写法更不容易写错？**

### 对照二：多列波叠加

叠加两列同频波，相位分别是 a 和 b：

| 用 cos | 用复指数 |
| --- | --- |
| cos(a) + cos(b) = 2·cos((a+b)/2)·cos((a−b)/2) | e^(ia) + e^(ib) = 2·e^(i(a+b)/2)·cos((a−b)/2) |
| 要用一条独立的"和差化积"公式 | **相位直接相加**，模与相位的规则自动生效 |

再想一下：如果叠加的不是两列而是五列，甚至要对整个孔径积分（衍射就是这种情况），
**哪一种写法的运算量涨得慢？**

### 结论（你自己的答案，2026-09-25）

> **"因为复指数把对于 cos 和 sin 的求导（求导过程中 cos 和 sin 会相互跳）
> 变成对于指数的求导（每次都只乘一个常数），把和差化积变成相位直接相加。"**

## 与光学的连接（这一节是本周真正的目的）

### 连接一：波就是一个复指数

一列沿 x 传播的单色波，电场可以写成：

```
E(x, t) = Re[ A · e^( i(ωt − kx + φ₀) ) ]
```

拆开看：`A` 是振幅（也就是模），指数上那一整坨是**相位**：

```
相位 Φ = ωt − kx + φ₀
```

其中：`ω = 2πν` 是角频率，`k = 2π/λ` 是波数。

**相位怎么变**

- 固定位置看：相位随 `t` 以 `ω` 的速度增加
- 固定时刻看：相位随 `x` 以 `−k` 的速度减少
- 追着"相位不变"的点走，它移动的速度就是 `ω / k = 波速`

### 连接二：相位差与光程差

两束光走过不同的路径，会积累不同的相位。关系是：

```
Δφ = (2π / λ) · ΔL          ΔL 是光程差
```

（光程 = 路径长度 × 折射率；真空中光程差就等于路径差）

| 光程差 | 相位差 | 结果 |
| --- | --- | --- |
| `0` 或 `λ` | `0` 或 `2π` | 完全同相，加强 |
| `λ/2` | `π` | 反相，抵消 |
| `λ/4` | `π/2` | 中间态 |

**【自己推，对应卡片 C11】**

迈克尔逊干涉仪里，把一面镜子**移动 `λ/4`**——

1. 光在这条臂上往返，所以光程变化是位移的**几倍**？
2. 光程差总共变化多少？
3. 对应的相位差是多少？
4. 条纹会移动**几条**？（提示：相位差变化 `2π` 才算移动一整条）

把四步都写在纸上。这题做对了，你对干涉的理解就落地了。

### 连接三：干涉就是两个复指数相加

两束等振幅的光，相位差为 `Δφ`：

```
A·e^(iΦ) + A·e^(i(Φ+Δφ)) = A·e^(iΦ) · ( 1 + e^(iΔφ) )
合振幅 = A · |1 + e^(iΔφ)|
```

**【自己推，对应卡片 C09】** 证明：

```
|1 + e^(iΔφ)| = 2·|cos(Δφ/2)|
```

（提示：先提出 `e^(iΔφ/2)` 这个公因子，再用欧拉公式的反向形式把两个指数变回余弦）

推出之后你会得到：

| 相位差 Δφ | 合振幅 | 强度（振幅平方） |
| --- | --- | --- |
| `0` | `2A` | 最大（`4A²`） |
| `π/2` | `√2·A` | 一半 |
| `π` | `0` | 完全抵消 |

**这就是双光束干涉公式的全部来源。**
后面所有干涉实验（迈克尔逊、马赫曾德尔、法布里珀罗）都从这一行出发。

> 注意：这里假设**两束光强度相同**。强度不同时条纹不会完全消掉——
> 那个比值就是"条纹可见度"，等你做干涉实验时会用到。

## 常见坑（至少踩过三个才算读过）

1. **把"相位"和"相位差"混着说。** 单个波的相位是相对的；物理上有意义的是相位差。
2. **忘记辐角可以差 `2π`。** 同一个复数有无穷多种相位写法，所以"谁的相位大"这种比较通常是错的问法。
3. **以为复数能比大小。** 复数没有序关系，`z₁ > z₂` 是无意义的。
4. **用度数算相位。** 相位一律用弧度——这是 §4 专门讲弧度制的原因。
5. **以为"取实部"是丢掉一半信息。** 复数是完整的记账方式，实部只是最后读数。
6. **把"模"和"实部"搞混。** `|z| ≥ |实部|`，等号只在 `z` 是实数时成立。
7. **把虚轴上的数写成 `iy`。** 纵轴画的是 `y` 本身。

## 关键公式速查

| 名称 | 式子 |
| --- | --- |
| 欧拉公式 | `e^(iθ) = cosθ + i·sinθ` |
| 反向形式 | `cosθ = (e^(iθ)+e^(−iθ))/2`，`sinθ = (e^(iθ)−e^(−iθ))/(2i)` |
| 模 | `abs(z) = √(x² + y²)` |
| 共轭乘积 | `z · z* = abs(z)²` |
| 极坐标乘法 | 模相乘，辐角相加 |
| 极坐标除法 | 模相除，辐角相减 |
| 纯相位因子 | `abs(e^(iθ)) = 1` |
| 旋转 | 乘以 `e^(iφ)` ＝ 逆时针转 φ |
| 相位差与光程差 | `Δφ = 2π·ΔL/λ` |
| 双光束干涉 | 合振幅 `= 2A·abs(cos(Δφ/2))`，强度 ∝ `cos²(Δφ/2)` |

## 三个必做的手写推导（【纸】，不许在屏幕上做）

1. 把 `1/(1+i)` 化成 `x + iy` 形式
2. 从 `e^(iθ)` 的幂级数导出 `e^(iθ) = cosθ + i sinθ`
3. 证明 `abs(1 + e^(iΔφ)) = 2·abs(cos(Δφ/2))`

第三个是重点——它是你以后所有干涉计算的母公式。
三个都推完之后，去做骨架自测。

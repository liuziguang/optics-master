# 日志

一个月一个文件，命名 `YYYY-MM.md`。

## 为什么要有日志

因为长期项目里最重要的信息是**过程**：你什么时候卡住、卡了多久、怎么出来的。
笔记记录知识，日志记录你自己。三年后回过头看，日志是唯一能告诉你"我在进步"的证据。

## 每次会话写什么（2 分钟）

用 `../templates/学习会话.md`，核心是三行：

1. 今天做了什么
2. 有什么被推翻或修正
3. 下次从这里继续（**这条最重要**，它让下次启动成本接近零）

## 每周复盘（20 分钟）

用 `../templates/周复盘.md`。

## 月度小结（30 分钟）

- 这个月完成了哪些实验 / 仿真 / 章节
- 能力地图上哪些项有证据可以上调
- 下个月唯一最重要的目标
- 器材、预算、时间的实际消耗（用于校准前置条件）

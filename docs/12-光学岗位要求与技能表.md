# 12 光学岗位要求与技能表

> **为什么要做这件事**：你未来的职业不是光学，所以这份文档的目的不是求职，
> 而是**用真实岗位要求来校准"专家"这两个字的定义**。

> 这份文档是**市场认为应该有什么能力**。两者对照，才能看出我的地图哪里是想象。
>
> **本文档有两轮**：
> - **第 1 到 8 节 + 附录 A**：英文市场，22 份企业岗位描述（集成光子与量子计算方向）

>
> 只想看结论的话，直接跳到 **第 10 节（中英对照）** 和 **第 11 节（对项目的结论）**。

## 2. 样本偏差（必须先说，否则会误读后面的百分比）

**这 22 份 JD 全部来自"集成光子 + 量子计算"这一个细分方向。**
这个方向的特点是：

- 用硅光、芯片化，而不是分立镜片
- 卖点在"通道数、良率、封装"，不是"成像质量"
- 因此**硅光、低温、封装、自动测试**的比例被显著放大

**样本里明显偏少甚至没有的**：

| 缺失方向 | 那里会高频出现什么 |
| --- | --- |
| 镜头与相机设计 | Zemax／Code V、像差理论、公差分析、MTF 实测 |
| 激光加工与工业激光 | 功率、光束整形、工艺窗口、切割质量 |
| 天文与空间光学 | 大口径镜面、支撑结构、热变形、杂散光 |
| 计量与检测院 | 不确定度、溯源、标准器、校准规范 |
| 消费光学（手机／车载） | 良率、成本、模组装配、量产公差 |

**所以：下面的百分比是"这份语料里的比例"，不是"整个行业的比例"。**
把它当**需求清单**用，不要当**权重分布**用。

## 3. 行业里的岗位地图

按职能分，这 22 个岗位可以归成六类：

| 职能 | 典型岗位名 | 实际干什么 | 门槛 |
| --- | --- | --- | --- |
| 光学设计 | Optical Engineer、Photonics Architect | 定义光路／器件结构，做仿真与优化，定指标 | 博士居多 |
| 器件与版图 | Photonic Device Design、Layout Engineer | 设计器件与版图，跑工艺规则，出流片文件 | 硕博 |
| 激光与光源 | Laser Design Engineer、Laser & SOA Characterization | 设计激光器／半导体光放大器，测阈值、线宽、RIN | 博士或资深 |
| 光机与封装 | Mechanical Engineer (Photonic Systems)、Optical Packaging | 设计镜座／封装，做公差链、热与应力、装配工艺 | 本硕＋经验 |
| 测试与标定 | Test／Validation／Calibration Engineer | 搭测试台，写自动化脚本，出数据与判据 | 本硕 |
| 实验与装配 | Optics Technician、Integration Engineer | 搭光路、对准、光纤耦合、故障排查 | 本科／专科＋动手 |

**一个对你有用的观察**：六类里，只有第一类是"纯光学理论"，
其余五类都是**光学 ＋ 某个工程领域**的组合。行业里纯做理论的岗位，
比"学光学的人"想象的要少得多。

| 测量与误差、标定、数据自动化 | **覆盖良好**，S0／`06`／`sim/` 都在这条线上 |
| 光机、热、对准、光纤 | **覆盖尚可**，靠 Yoder 两卷与 G2 目标 |

| 封装工艺、可制造性、良率、供应商 | **不覆盖**——这是行业专用能力，业余条件下也做不了 |
| 高速电学测量（VNA／AWG） | **不覆盖**——需要昂贵设备，与你的主线无关 |

| 跨职能协作 | **无法覆盖**——业余项目没有"职能"可跨，这是你放弃职业路径后必然失去的部分 |

**一句话**：本项目覆盖的是这六类岗位里**"光学设计"与"测试表征"**两类，
外加一部分"实验装配"。**这正是业余条件能做到的最大公约数**，不是遗憾。

## 8. 方法与局限（诚实的部分）

1. **样本只有 3 家公司的招聘板。** 方向集中在集成光子与量子计算，
   所以"硅光 63%""低温 54%"这类数字不能外推。
2. **22 份不足以做统计结论**，只够做**需求清单**。
3. **公开招聘描述有系统性的偏乐观**：写上去的是"希望有"，实际筛选往往更窄；
   同时"要求 5 年经验"的岗位现实中可能接受 4 年。
4. **本文档的抓取受网络条件限制**：搜索引擎（Google／DuckDuckGo）与
   主流招聘聚合站在此网络下不可用，百度在连续请求后开始限流，
   因此最终选用了 Greenhouse 的公开 JSON 接口——它稳定、结构化、可核验。
5. **未覆盖中文招聘市场**。国内岗位（光学设计、激光应用、光电仪器）
   的比例结构与此差别很大，如果以后需要，应该单独抓一轮。

# 第二轮：中文市场（2026-09-23）

## 9. 中文市场

### 9.1 先说清楚：中文企业岗位的正文没抓到

这一轮花了很大力气，但**中文商业招聘网站的岗位正文基本没拿到**。原因值得记下来，
因为以后再抓还会遇到：

| 障碍 | 具体情况 |
| --- | --- |
| 页面靠 JS 渲染 | BOSS直聘、猎聘、智联、前程无忧的列表与详情都是前端渲染，抓到的 HTML 里没有岗位文字 |
| 反爬 | 职友集在连续请求后跳到验证页（`tips/valid.php`） |
| 搜索链接是会话绑定的 | 360 搜索能用，但结果链接是一次性跳转（`so.com/link?m=...`），换个会话就失效，且部分直接跳回首页 |
| 百度限流 | 第一次请求正常，之后只返回 1.4KB 的拦截页 |
| 境外搜索引擎不可用 | Google、DuckDuckGo、以及本地 Clash 代理（127.0.0.1:7890）全部不通 |

**所以这一轮的策略改成了：找服务器端渲染的权威源，而不是硬啃招聘网站。**
结果是拿到了比企业 JD 更硬的东西。

### 9.2 拿到的核心数据：长春光机所的招聘岗位需求表

**中国科学院长春光学精密机械与物理研究所（CIOMP）** 是中国光学最强的研究机构之一，
它的招聘页面上挂着两张附件：一张 **Excel 岗位需求表**、一份 **Word 申请说明**。

这份 Excel 是本轮最有价值的收获——**它是结构化的，不是散落的招聘广告**：

| 分类 | 岗位数 | 招收人数 |
| --- | --- | --- |
| 光学类 | 54 | 91 |
| 机械类 | 42 | 72 |
| 电子类 | 69 | 109 |
| 物理化学材料类 | 24 | 37 |
| 其他类（总体设计） | 8 | 13 |
| **合计** | **197** | **322** |

每一行有九个字段：序号、岗位分类、**岗位名称**、**岗位研究方向及主要研究内容**、
**学历要求**、**专业要求**、招聘人数、需求人、邮箱。

> **为什么这一份比企业 JD 更有信息量**：企业 JD 是筛选用的（写上去的是"希望有"），
> 而研究所的需求表是按课题组的实际缺口排的，**每个岗位对应一个具体研究方向和招收人数**。
> 它暴露的是**行业真正需要什么方向的人**，而不是 HR 想怎么写。

### 9.3 光学类 54 个岗位的细分

按岗位名称归类，中国顶级光学研究所的需求结构是这样的：

| 细分 | 岗位数 | 招人 |
| --- | --- | --- |
| **光学设计** | 21 | 最多 |
| **光学检测** | 10 | 次之 |
| **光学理论** | 8 | |
| **光学镀膜** | 5 | |
| **光学加工** | 4 | |
| **激光技术** | 3 | |
| 光通信 | 1 | |
| 光机装调 | 1 | |
| 光栅研制 | 1 | |

**这张表本身就是一句结论**：在科研院所里，"光学设计"和"光学检测"占了一半以上。
**做设计的人多，验收设计的人也不能少**——这与本项目"理论必须配测量"的设定完全一致。

### 9.4 门槛：光学类岗位里没有一个本科

| 学历要求 | 光学类 | 机械类 | 电子类 | 物理化学材料类 |
| --- | --- | --- | --- | --- |
| 博士 | 23 | 14 | 19 | 15 |
| 硕士及以上 | 31 | 28 | 50 | 9 |
| 本科 | **0** | **0** | **0** | **0** |

**科研院所的入口门槛是硕士，光学类里四成以上要博士。**
这和企业侧（第 4.8 节：本科占 22%）形成鲜明对比——
**企业按职能分流，院所按学历卡线。**

按细分看学历分布，还能看出哪些方向更"学术"：

| 细分 | 博士 | 硕士及以上 |
| --- | --- | --- |
| 光学设计 | 11 | 10 |
| 光学检测 | 6 | 4 |
| 光学理论 | 5 | 3 |
| 光学镀膜 | 1 | 4 |
| 光学加工 | 0 | 4 |
| 激光技术 | 0 | 3 |

**"光学理论"和"光学检测"的博士比例最高，"光学加工""镀膜""激光技术"更偏工程**。

### 9.5 专业要求：光学工程几乎是硬通货

在 54 个光学类岗位里：

| 专业关键词 | 出现岗位数 |
| --- | --- |
| 光学 | 51 |
| 光学工程 | 48 |
| 物理学 | 12 |
| 仪器科学与技术 | 10 |
| 凝聚态物理 | 6 |
| 电子科学与技术 | 6 |
| 计算机 / 软件工程 | 各 5 |
| 机械工程 / 控制科学 / 材料 | 各 5 |

**几乎所有岗位都接受"光学／光学工程"，且绝大多数同时列出周边专业。**
换句话说：**这个行业要的不是纯光学，而是"光学＋一个邻域"**——
这与第 3 节从英文样本得到的结论完全一致，只是中文侧列得更直白。

### 9.6 研究内容里真正的技术重心

对 54 个光学岗位的"研究方向及主要研究内容"做关键词统计：

| 关键词 | 出现次数 | 关键词 | 出现次数 |
| --- | --- | --- | --- |
| 激光 | 34 | 光谱 | 8 |
| 成像 | 33 | 衍射 | 5 |
| **仿真** | **27** | 干涉 | 5 |
| 光学设计 | 21 | 超表面 | 4 |
| **算法** | **20** | 镀膜（另计薄膜 14） | 4 |
| 薄膜 | 14 | 偏振 | 2 |
| 微纳 | 9 | 自适应 | 2 |

**两个值得注意的数字：仿真 27 次、算法 20 次。**
在一个光学研究所的岗位描述里，"仿真"和"算法"出现的频率几乎和"激光""成像"同级。

**这说明**：现代光学岗位的工作有很大一部分不是"在暗室里调光路"，
而是**在计算机里建模、优化、写代码**。这对本项目的启示是直接的——
`sim/` 那条轨道不是附属品，它和实验是平权的。

### 9.7 机构版图：一个光学研究所由什么组成

从申请说明里可以读到长春光机所的 26 个研究与技术支撑部门，这本身就是一份"行业地图"：

| 类别 | 部门 |
| --- | --- |
| 全国重点实验室 | 特种发光科学与技术、光学系统先进制造、动态光学成像与测量 |
| 空间光学 | 空间光学研究一部／二部／三部、空间新技术研究部、空间机器人中心 |
| 光电对抗与探测 | 光电对抗研究部、光电探测技术研究部、光束精密控制研究室 |
| 图像与计算 | 图像信息智能处理技术研究部、先进计算与数字工程研究中心 |
| 元件与工艺 | 光栅技术研究中心（国家光栅制造与应用工程技术研究中心）、光学集成制造中心、电装工艺与装联技术中心 |
| 测试与质量 | 质量检验与测试技术中心（国家光学机械质量检验检测中心） |
| 前沿与平台 | 微纳光子学与材料国际实验室、Bimberg 中德绿色光子学研究中心、吉光实验室（省级实验室）、精密仪器与装备研发中心 |

**三个可以直接读出来的事实**：

1. **"制造"与"检测"各占一个国家级中心**（光学系统先进制造全国重点实验室、
   国家光学机械质量检验检测中心）。检验和制造在这个行业里不是配角。
2. **光栅有独立的国家级工程技术研究中心**。光栅是光谱与激光的核心元件，
   值得记住。
3. **有专门的"先进计算与数字工程研究中心"**，再次印证上一节的"算法与仿真"。

## 10. 中英两轮对照

| 维度 | 英文样本（22 份企业 JD） | 中文样本（197 个院所岗位） |
| --- | --- | --- |
| 行业侧重 | 集成光子、量子计算 | 空间光学、激光、成像、光栅、镀膜 |
| 学历 | 博士 40%，本科 22%（技师类） | 博士 43%，硕士 57%，**本科 0** |
| 核心专业 | 光子学、物理、EE | 光学工程、光学 |
| 高频工具 | Python 59% | 仿真 27 次、算法 20 次（未见具体软件名） |
| 高频概念 | 硅光、光纤、低温、封装 | 激光、成像、薄膜、微纳、光谱 |
| 岗位结构 | 设计与测试分离，封装独立成岗 | **光学设计 21／检测 10／理论 8** |
| 共同点 | 光学＋邻域；测量与仿真各占一半；"光学"很少单独存在 | 同 |

**两轮下来，唯一稳定不变的三条结论**：

1. **没有"纯光学"岗位。** 每一类都要么偏设计、要么偏检测、要么偏器件，
   都带着一个工程邻域。
2. **测量能力与设计能力同等重要。** 中文侧"检测"独立成岗且数量第二，
   英文侧"test"出现在 77% 的岗位里。
3. **计算能力已经内嵌。** 英文侧 Python 59%，中文侧"仿真 + 算法"合计接近最高频词。

## 11. 更新后的结论：对项目意味着什么

把两轮的结果合起来看，本项目原来的设计基本站得住，但有两点要修正：

| 项目原有设定 | 两轮证据 | 结论 |
| --- | --- | --- |
| 主线是光源工程 | 中文侧"激光"出现 34 次为最高频 | **支持** |
| 理论必须配测量实验 | 检测类岗位占光学类 10/54；英文侧 test 77% | **支持，且应加强** |
| 编程只是工具、不设学习目标 | 两侧都显示计算能力是刚需 | **需要修正**：不作为"学习目标"可以，但**不能低配**——至少要把仿真与数据自动化练到能独立完成一次全自动测量 |
| `sim/` 是辅助轨道 | 中文侧"仿真 27 + 算法 20" | **需要修正**：把 `sim/` 从"辅助"提升为与实验平权的轨道 |
| 光学设计（Zemax 类）是 S1 的一部分 | 中文侧光学设计是最大细分（21/54） | **支持，且值得提前**：如果只做一件事来贴近中文市场，那就是**成像设计与像差** |

**一句话**：这两轮都指向同一个判断——
**这个行业不缺"懂光学的人"，缺"能把光学算出来、做出来、再测回来的人"。**
而后者恰好是本项目从第一天起就在要求的东西。

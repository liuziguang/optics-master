# 08 前置补课计划

> 你的答案是"学过忘了，先补一段时间"。
> 这份计划的目标是：**用最少的复习时间，补上光学真正需要的数学与物理工具，然后立刻回到光学**。

## 1. 最重要的一条原则：按需补，不要重学

重学一遍微积分是初学者最经典的陷阱：花三个月，考了高分，
然后发现光学里真正用到的只有那么十几个工具。

**正确做法：**

1. 先做下面的诊断自测（约 90 分钟），标出不会的题。
2. 只复习不会的题对应的工具。
3. 复习时**用光学问题当练习**，不要用纯数学题。
4. 补课与 S0/S1 并行推进，不要"补完再开始光学"。

预计总时长：**4 到 10 周**，约占每周可用时间的六成，其余时间直接做光学。

### 明确不在本计划范围内

**编程与硬件电子不在本项目的补课范围内。** 这两项能力由另一个项目负责维护，
本项目只把它们当作现成的工具使用（写仿真脚本、驱动仪器、焊接电路）。

所以本计划只补三样：**数学工具、电磁学、实验误差与数据处理**。
不要在这里额外增加编程课程，那会挤掉真正稀缺的光学时间。

## 4. 自评标准

| 答对题数 | 诊断 | 行动 |
| --- | --- | --- |
| 18–20 | 数学其实没忘，只是手生了 | 只做 2 周热身，直接开始 S0/S1 |

## 5. 答案要点

<details>
<summary>点开查看（先做完自测再看）</summary>

1. cos(ωt − kx) = Re[e^{i(ωt−kx)}]。用复指数的原因：微分变成乘 iω，线性叠加变成加法，
   相位关系一目了然；只需最后取实部。
2. (1+i)⁸ = (√2 e^{iπ/4})⁸ = 2⁴ e^{i2π} = 16。
3. 3 + 4i = 5 e^{i·arctan(4/3)} ≈ 5 e^{i0.927}。
4. θ − sinθ ≈ θ³/6 = 1.667×10⁻⁴ rad；相对误差 (θ−sinθ)/sinθ ≈ θ²/6 ≈ 0.17%。
   要点是"误差是 θ 的二次量级"。
5. ∫₀^∞ x e^{−ax}dx = 1/a²。
6. √π。
7. y = y₀ e^{−x/τ}；τ 是衰减到 1/e 所需的时间（时间常数）。
8. x = e^{−γt}(A cos ω_d t + B sin ω_d t)，其中 ω_d = √(ω₀² − γ²)。
9. 代入得 (v² − v²)f″ = 0，成立；v 是波速（相速）。
10. ∇·A = 3；∇×A = 0。
11. ∇·E = ρ/ε₀，∇·B = 0，∇×E = −∂B/∂t，∇×B = μ₀J + μ₀ε₀ ∂E/∂t。
12. M² = [[1, 2d], [0, 1]]，代表自由空间传播距离 2d（薄透镜/平移矩阵）。
13. 例：旋转矩阵与缩放矩阵不可交换；光学中"先过透镜再传播"与"先传播再过透镜"结果不同。
14. (4/π)(sin ωt + sin3ωt/3 + sin5ωt/5 + …)。
15. (f∗g)(x) = ∫f(τ)g(x−τ)dτ；成像系统对物体的作用就是卷积 PSF，而频域是简单相乘，
   这正是引入 MTF 的原因。
16. f(a)。
17. b = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²，a = ȳ − b x̄。
18. 角半径 θ ≈ 1.22 λ/D（第一暗环），式中 1.22 来自 3.83/π。
19. σ_z/z = √[(σ_x/x)² + (σ_y/y)²]（x、y 独立时）。
20. sin(5°) ≈ 5·π/180 = 0.08727 rad，精确值 0.08716，相对误差约 0.13%。

</details>

## 6. 补课的资源建议

按需查，不要通读：

| 缺口 | 建议资源 |
| --- | --- |
| 复数与复指数 | 任意工程数学教材的"复数"一章，重点看极坐标与欧拉公式 |
| 泰勒展开与小角近似 | 高等数学"泰勒公式"一节，自己做 3 道题 |
| 常微分方程 | 侧重一阶线性与二阶常系数齐次，足够应付速率方程与谐振子 |
| 矢量微积分 | 《电动力学》（郭硕鸿或 Griffiths）第 1 章，**必补，不要跳过** |
| 傅里叶变换 | 任意"信号与系统"教材的傅里叶部分，重点：变换对、卷积、δ 函数 |
| 线性代数 | 只需矩阵运算与特征值，不需要抽象空间理论 |
| 概率统计 | 分布、期望、方差、最小二乘，重点看"误差分析" |
| 实验数据处理 | 大学物理实验教材的"不确定度"章节 |

## 7. 一个关键建议

**不要买新的数学教材。** 找一本你已经有的、当年考过及格的教材，
或者网上一份讲义，只查需要的章节。

补课的目标不是"学会数学"，而是"能读懂光学教材里的推导"。
一旦发现某个数学工具在光学里被反复用到，你自然会想把它真正搞懂——
那种"因为需要而学"的效率，比"因为应该而学"高一个量级。

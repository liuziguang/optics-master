# 05 运行手册

> 这是你每次坐下来时实际执行的部分。目标：让"开始"这件事不需要意志力。

## 1. 会话类型（按可用时间选）

| 类型 | 时长 | 动作 | 产出 |
| --- | --- | --- | --- |
| 每日打卡 | 1–3 分 | 记录今天做了什么（允许写"无"）+ 写出下一步 | 一行记录 |
| 微会话 | 15 分 | 读一页书 + 写 3 行笔记；或做一道题；或复现一个公式 | 1 条笔记 |
| 标准会话 | 60–90 分 | 45 分深读+推导，20 分动手或仿真，10 分记录 | 1 篇笔记 + 1 个数据点 |
| 实验会话 | 2–4 时 | 明确目标 → 搭 → 测 → 收尾（收尾必须有） | 1 份实验记录 |
| 深潜日 | 半天到全天 | 只做一件硬事（搭一台设备 / 推导一个大主题） | 里程碑 |

规则：微会话也要落盘。没有落盘的会话在系统里等于没发生。

**每日打卡是独立的一层，不是"微会话"。** 它的作用是让中断可见，
详见 `11-监督机制.md`。

## 2. 每周节律（已按你的实际情况定制）

你的可用时间集中在周末，所以采用**双块结构**。工作日不安排任务。

| 时段 | 时长 | 内容 |
| --- | --- | --- |
| 周六块 | 3 小时 | 理论深读 + 推导 + 搭建 |
| 周日块 | 2 小时 | 测量 + 数据处理 + 收尾 + 复盘 |

补课期的分配见 `03-十年路线图.md` 第 2 节。

周六块的结束动作只有一个：**写下"下次从这里继续"的第一步具体动作**。
周日块的结束动作只有一个：**把装置拆掉、数据归档、笔记落盘**。

周日复盘只回答四个问题：

1. 这周实际做了什么？（照实写，包括什么都没做）
2. 哪个理解是错的 / 被修正了？
3. 下周唯一最重要的一件事是什么？
4. 有没有需要买、修、借的东西？

## 3. 笔记规范

### 三层结构

```text
notes/
├─ capture/      随手记（原始、粗糙、可丢弃）
├─ atoms/        原子笔记：一个文件 = 一个概念，可被引用
└─ index/        索引地图：按主题把原子笔记串起来
```

### 原子笔记：文件名即结论

好的文件名：`干涉条纹漂移的主要来源是机械与温度.md`
坏的文件名：`干涉笔记.md`

每条原子笔记必须包含：

- 一句话结论
- 成立条件（在什么近似或范围下才对）
- 推导或来源
- 一个能验证它的实验或仿真
- 与哪些笔记相连

### 理论笔记必须有的四样东西

1. 物理图像（能用一张图讲清）
2. 支配方程
3. 极限检查（取极限是否退化到已知结果）
4. 数量级估算（"典型值是 1 mm"往往比"公式正确"更有用）

## 4. 实验记录规范

每次实验用 `templates/实验记录.md`，必须包含：

- 目的与可证伪的假设
- 器材清单（含型号，便于复现）
- 光路图或装置照片
- 原始数据文件路径（原始数据永不修改）
- 处理过程与脚本路径
- 结果与理论值对比 + 偏差解释
- 失败与异常记录（最容易被忽略、最有价值）
- 下次改进项

目录命名：`lab/实验名/YYYY-MM-DD-简述/`

## 5. 版本控制

这个目录是 git 仓库。建议每次会话结束提交一次：

```powershell
git add -A
git commit -m "S1: 焦距多方法测量实验完成"
```

- 哪怕只有一行改动也提交。
- 大文件（原始图像、数据集）用 `.gitignore` 排除，另存并定期备份。
- 每周看一次 `git log --oneline`，这是最便宜的动力来源。

## 7. 断线恢复协议

预计会断。出差、生病、工作爆炸、毕业找工作、搬家都会发生。规则：

> 完整的中断阈值与降级流程见 `11-监督机制.md`。下面是速查版。

| 断线时长 | 恢复动作 |
| --- | --- |
| 少于 1 周 | 直接继续，不补课 |
| 1–4 周 | 花 20 分钟重读上次的笔记，然后做 1 次微会话 |
| 1–3 月 | 不要试图补回来。重做一次阶段校准，从当前实际水平接着走 |
| 超过 3 月 | 重读 `00-项目章程.md` 和 `01-前提条件.md`，重新确认兴趣优先级，必要时降低节奏档位 |

铁律：**断线时不做道德审判，也不追补。** 只降级，然后继续。
把断线的具体日期与触发事件记到非公开记录里，三个月后回看会看到模式。

## 8. 激光安全守则（强制）

1. 3B/4 类激光必须戴对应波长的防护镜，且镜片不能是唯一防线。
2. 光路尽量低于或高于视平线，绝不平齐眼睛。
3. 光束终端必须有挡光板，禁止敞开光路对着门口或窗户。
4. 调光路前摘下手表戒指，避免镜面反射。
5. 不直视镜面反射方向；用卡片、荧光屏、红外感应卡观察。
6. 单独实验时告知家人；无人看管时必须关光。
7. 红外激光尤其危险（不引发眨眼反射），必须用探测器而非眼睛确认。

## 9. 工位设置建议

- 一块沉重、低重心、可长期占用的桌面（越重越好）。
- 可调照明：实验时暗，读笔记时亮。
- 一个固定的常用元件盘，减少每次找东西的时间。
- 相机和记录本放在手边。没有记录，实验等于重做。
- 一块白板或大纸，用于临时画光路。

# 14 软件学习路线

> **由来**：2026-09-26 用户要求——未来的学习里至少要掌握一种光学常用软件，并且要包括 COMSOL。
>
> 这份文档回答三件事：**学哪几个、什么时候学、学到什么程度算会。**

## 1. 结论：三件套，不是一堆软件

| 角色 | 软件 | 一句话定位 |
| --- | --- | --- |
| **专业级几何光学** | **Zemax OpticStudio** | 中文光学岗位里最硬的通货（"光学设计"是最大细分） |
| **耦合仿真** | **COMSOL Multiphysics** | **唯一能把你主线里的"光 — 热 — 力"放进同一个模型算的工具** |
| **永久底座** | **Python 生态** | 免费、不受身份影响、可自动化、能陪你一辈子 |

**其余一律不学**（Lumerical、CST、LightTools、TracePro……）。理由见第 3 节。

## 2. 三条判据

选软件不看名气，看这三条：

1. **对北极星有没有用**：能不能直接服务于 `07-北极星-极限光源.md` 里的 G0 到 G6。
2. **毕业后还能不能用**：你是学生，很多授权随身份消失。**能陪你走十年的才有资格当底座。**
3. **有没有可验证的产出**：学完必须能拿出一个对得上数结果的东西，否则等于没学。

按这三条筛，剩下的就是上面三件套。

## 3. 为什么排除其他软件

| 软件 | 排除理由 |
| --- | --- |
| Lumerical / Ansys | 强是强，但授权极贵，且面向集成光子芯片——**不是你的主线** |
| CST Studio Suite | 你已装，长处在天线与微波；光学上能做的事 COMSOL 覆盖得更好，**学两套电磁软件是浪费** |
| LightTools / TracePro | 照明设计专用，你的主线用不到 |
| FRED / SPEOS | 同上，且授权昂贵 |
| **OSLO EDU** | **不排除，作为免费备选**：毕业后想继续做几何光学设计，它是能长期用的替代品 |
| **MEEP** | **不排除，作为免费备选**：开源 FDTD，可替代 COMSOL 的波动光学部分 |

**一句话**：主用商业软件拿专业级手感，同时**始终有一条免费的路能走下去**。

## 4. COMSOL 对你主线的真正价值（这一点最容易被搞错）

很多人以为 COMSOL 在光学里的用法是"画个波导看光怎么传"。
**对你来说不是。**

你主线的瓶颈在 **G2（波长稳定到 pm/K）** 和 **G4（腔锁定）**——
而这两件事的本质是：

```
电 → 热 → 机械变形 → 光学性能变化
```

**这是一条多物理场链，Zemax 算不了，Python 也只能各算一段拼起来。**
COMSOL 能把它装进一个模型里。这就是它在你的项目里不可替代的位置。

顺带它也覆盖：

| 用途 | 对应阶段 |
| --- | --- |
| 多层膜反射率（与传输矩阵法互验） | S3 |
| 激光器热—光耦合、波长温漂 | S4 / G2 |
| 波导模式、光栅、超表面 | S6 |
| 光机结构的应力与热变形 | 配合 `library/12-光机设计与结构/` 的 Yoder 两卷 |

## 5. 授权与可持续性（时间敏感）

**先确认一件事，它比学哪个软件更重要。**

| 问题 | 为什么重要 |
| --- | --- |
| 你现在用的 COMSOL 授权从哪来？ | 决定毕业之后还能不能打开 |
| 学校有没有校园授权？ | 你是学生，这是最省事也最正当的路径 |
| Zemax 能不能申请学生版？ | **学生身份一旦结束就申请不到了** |

**两件必须趁现在做的事**：

1. **立刻查学校的正版软件目录**，看有没有 COMSOL / Zemax / MATLAB 的校园授权。
2. **如果 Zemax 有学生版，现在就申请**——这是不可逆的窗口。

**不建议把长期技能建立在一个随时会失效的安装上。** 这不是道德说教，是工程判断：
（a）它可能在某次更新后打不开；（b）如果以后要把结果公开或用于工作，
工具授权的来源会影响你能不能这么做。**所以第 1 节里 Python 是底座，商业软件是加分项。**

## 6. 什么时候学：绑到阶段上，不单独立课

**软件不单独排课。** 单独学软件会变成"跟着教程点了一遍菜单，然后忘了"——
这是最容易浪费时间的方式。正确做法是**在需要它的那一刻学**：

| 阶段 | 学什么 | 触发它的任务 |
| --- | --- | --- |
| S1 后半段 | **Zemax** 基础 | 要设计一个有像差指标的成像系统 |
| S3 | **COMSOL Wave Optics** | 要算多层膜反射率、要和传输矩阵法对照 |
| S4 / G2 | **COMSOL 热—光耦合** | 要解释激光波长为什么随温度漂 |
| 全程 | **Python** 不停手 | 每次测量都要数据处理 |
| S6 | 选学 MEEP 或 COMSOL 波动 | 做微纳光子学时才需要 |

**每个阶段只学这个阶段用得上的功能**，不要求"把软件学完"。

## 7. 验收标准：必须有对得上数的产出

这一条是整份文档最重要的部分。**软件有没有学会，不看会不会点菜单，看能不能拿出结果。**

| 软件 | 阶段 | 验收产出 | 及格线 |
| --- | --- | --- | --- |
| Zemax | S1 后半 | 设计一个双胶合消色差物镜 | 轴上与边缘的 MTF 达标，**并能解释每个面在做什么** |
| COMSOL | S3 | 多层膜的反射率曲线 | **与传输矩阵法（Python）算出的曲线重合** |
| COMSOL | S4 / G2 | 激光器温漂模型 | 预测的波长漂移与实测同量级（±50% 内） |
| Python | 全程 | 任一实验的自动化脚本 | 一条命令跑完采集 → 处理 → 出图 |
| 免费备选 | 毕业后 | OSLO 或 MEEP 复现前面任一结果 | 与商业软件结果一致 |

**注意最后一行**：它保证你的能力不挂在任何一个付费授权上。

## 8. 仿真的铁律（防止"好看的假结果"）

仿真最容易出的问题不是算错，是**算出一个看起来很像对的结果，然后信了**。

所以本项目对仿真只有一条硬规矩：

> **每一个仿真都必须有一个对照物——解析解、另一种算法、或者实测数据。**
> 三者都没有的，只能当作示意图，不能当作结论。

配套的三条自查：

| 检查 | 问自己 |
| --- | --- |
| 模型假设 | 我用的是标量还是矢量？近轴还是非近轴？相干还是非相干？ |
| 单位 | 全线一致吗？（全 SI 或全 mm/mrad，不要混） |
| 收敛 | 网格加密一倍，结果变了吗？变了说明还没收敛 |

**建议**：第一次跑任何仿真，都先用一个**有解析解的小问题**验证工具本身
（例如平行平板干涉、单缝衍射）。工具没问题了，再去做没有解析解的问题。

## 9. COMSOL 的最小必要路径（省时间版）

COMSOL 的体量足够让人迷失。你只需要四条：

1. **几何建模**：会画二维轴对称和三维简单体，会参数化尺寸
2. **选物理场**：开始只学两个——`Wave Optics` 和 `Heat Transfer`
3. **网格与求解**：会用默认网格，知道什么时候要手动加密
4. **后处理取数**：会画曲线、会导出数据（**导出的数据拿回 Python 分析，不要在 COMSOL 里做数据分析**）

**不要碰**（除非真的需要）：App Builder、LiveLink、优化模块、代理模型。

**入门顺序**：

```
跑通一个官方 Application Library 示例
   → 把参数改成你自己的
   → 与解析解或实测对照
   → 写一条仿真记录（模板见 ../templates/实验记录.md）
```

本地已装的示例库在 `D:\COMSOL Multiphysics 6.4\COMSOL64\Multiphysics\applications\Wave_Optics_Module`。

## 10. 现在就能做的三件事（按优先级）

- [ ] **查学校的正版软件目录**，确认 COMSOL / Zemax / MATLAB 的校园授权情况
- [ ] **如果 Zemax 有学生版，立刻申请**（学生身份是硬窗口，过期不候）

## 11. 第一次跑通：用哪个示例（2026-09-26 补）

**不要随便挑一个示例。** 第一个示例要满足一个条件：**它必须有解析解**——
这样你同时学会两件事：软件怎么用，以及第 8 节那条"仿真必须对照"的铁律。

### 先做一步授权体检（1 分钟）

打开 COMSOL → 新建 → 模型向导，看**空间维度选择页之后的一级分类里有没有「光学」**。

- 有「光学」这一枝，并且能选到 **Wave Optics** 与 **Ray Optics** → 计划不变
- **没有 → 立刻告诉我**，`docs/14` 的方案要改（改用 MEEP + OSFP 等免费路线）

> 本机授权文件列出的产品名是 `SSQ_0000` 到 `SSQ_0003`，这类打包版通常是全模块解锁，
> 但**必须实际打开确认**，不要靠推测。

### 推荐第一个示例：`brewster_interface.mph`

位置：
`D:\COMSOL Multiphysics 6.4\COMSOL64\Multiphysics\applications\Wave_Optics_Module\`

为什么是它：

| 理由 | 说明 |
| --- | --- |
| **有解析解** | 布儒斯特角满足 `tan θB = n₂/n₁`，手算就能对照 |
| **对应本项目的实验** | S3 里你要用反射法测布儒斯特角求折射率——**仿真正好给那次实验做预演** |
| 规模小 | 二维单界面，十分钟能跑通 |

**做完这三步才算跑通**：

1. 打开模型跑一遍，找出反射率趋近于零的那个角度
2. **手算** `θB = arctan(n₂/n₁)`，与仿真结果对比
3. 写一条仿真记录（`../templates/实验记录.md`），把「假设 / 单位 / 收敛」三栏填上

### 另外两个示例，先记下来别打开

示例库里有两个模型**直接命中你的主线**，等到对应阶段再用：

| 示例 | 对应 |
| --- | --- |
| `sesam_laser_heating.mph` | **激光器加热 → 就是 G2 要做的"热—光耦合"** |
| `single_mode_fiber_coupling.mph` | 单模光纤耦合效率 → G1 的耦合问题 |

**其余示例留到需要时再开。** 一次性把示例库翻一遍，是另一种形式的"用收集代替学习"。

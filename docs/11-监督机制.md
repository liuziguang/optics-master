# 11 监督机制

> 这份文档存在的唯一原因：**这个项目的头号风险不是难度，是中断后无人知晓。**
>
> 已确认的历史失败模式是："没有日常监督，好几天的任务完不成就逐渐放弃了。"
> 这不是意志力问题，是**结构设计问题**。所以本文档是整个项目里优先级最高的一份。

## 1. 失败是怎么发生的（机制分析）

```
任务跨度过大（要几天才能做完）
        ↓
某一天没完成 → 缺口产生
        ↓
没有检查点 → 缺口无人看见
        ↓
缺口累积 → "我已经落后很多了"
        ↓
心理成本 > 继续的动力 → 放弃
```

三个环节都可以单独切断：**把任务切小**、**让缺口可见**、**引入外部观察者**。

## 2. 三层防线

| 层 | 解决什么 | 机制 |
| --- | --- | --- |
| **L1 任务粒度** | 防止缺口产生 | 任务必须小到"单次可完成" |
| **L2 每日检查点** | 让缺口可见 | 每天 1 到 3 分钟记录，允许空白 |
| **L3 外部监督** | 补上自我监督的失效 | 机器提醒 + 公开留痕 + 人类伙伴 |

三层缺一不可。只做 L1，中断了还是没人知道；只做 L2，任务太大还是会连续失败。

## 3. L1：任务粒度规则

### 唯一判据

> **如果一个任务你今天完不成，那它就不是一个任务，而是一个项目——必须继续拆。**

### 写法对照

| 错误写法（跨天） | 正确写法（单次可完成） |
| --- | --- |
| 学习傅里叶光学 | 读完 Goodman 第 2.1 节，写 5 行笔记 |
| 搭建干涉仪 | 把激光和第一个反射镜固定到底板上，拍照 |
| 把噪声降下来 | 测一次当前 RIN 频谱，存成图 |
| 补数学 | 做诊断自测的第 8 到 12 题 |
| 做完光源 | 把驱动电路焊好，测输出电流 |

### "下一个物理动作"原则

任何会话结束前，必须写下**下一个动作**，且这个动作要满足：

1. 5 分钟内能开始（不需要先想、先买、先查）
2. 不需要做决定
3. 具体到能直接被别人执行

写在每次会话的最后一行。这是让下次启动成本接近零的唯一办法。

## 4. L2：每日检查点

### 规则

- **每天一次，1 到 3 分钟。**
- **允许写"无"。** 什么都没做也照样记录。
- 不允许的是**忘记记录**——因为中断这件事本身必须可见。

### 格式（写入 `journal/打卡.md`）

```text
2026-09-22  无
2026-09-23  读完 2.1 节，一张图        下一步：把卷积定义抄一遍
2026-09-24  无（加班）
2026-09-25  算了两道题
```

一行就够。不要写成日记，否则打卡本身会变成负担，然后你连打卡都会放弃。

### 为什么"允许空白"很关键

如果规则是"必须做事才能打卡"，那么没做事的那天你就没法打卡，
检查点就会在**最需要它的时候**消失。空白记录比完美记录有用得多。

## 5. 中断阈值与恢复动作

| 连续未记录 | 自动触发 | 动作 |
| --- | --- | --- |
| 2 天 | 提醒 | 今天只需记录一行，哪怕写"无" |
| 3 天 | 恢复协议 | 把当前任务**砍一半**，或降级到 15 分钟微会话 |
| 7 天 | 降档 | 重读 `00-项目章程.md`，考虑把节奏档位下调 |
| 14 天 | 重启 | 按 `05-运行手册.md` 第 7 节走完整重启流程 |

**铁律：中断时不做道德审判，也不追补。** 只降级，然后继续。

## 6. L3：外部监督

自我监督已被证明失效，所以要引入外部观察者。按强度递增：

### 6.1 机器监督（已启用）

由 Codex 自动化在固定时间发起检查。它的作用是**消除"忘了"这个可能**。

特点：不评判、不催促、只提问。提问内容固定为三句：

1. 今天有没有碰光学？
2. 有没有卡住的地方？
3. 下一步的具体动作是什么？

### 6.2 公开留痕（进行中）

GitHub 的提交记录就是一条公开的连续性证据。

- 每天哪怕只提交一行日志，图上的方格就会亮一格。
- 空白会在贡献图上留下可见的空洞——**这是最温和也最有效的社会压力**。
- 不需要发帖、不需要写博客，只要提交。

### 6.3 人类伙伴（最强，待建立）

找一个真人做 accountability partner：朋友、同学、网友、社群里的人。

约定极简：

- 每周互相发一次消息，内容只有"本周做了什么、下周做什么"。
- 不需要对方懂光学，只需要对方会问"这周呢？"

**研究表明（也是常识）**：向一个具体的人承诺，履约率会显著高于只对自己承诺。
这条对"缺少日常监督"的失败模式是对症下药。

## 7. 每周复盘要新增的一问

在 `templates/周复盘.md` 的原有问题之外，加一问：

> **本周有几天没有记录？如果超过 2 天，是什么时候开始断的？**

断点的具体日期和触发事件，写进非公开记录。

## 8. 反模式清单（什么会破坏监督）

| 反模式 | 为什么有害 |
| --- | --- |
| 把打卡当成任务 | 打卡 30 天但一次实验都没做，说明系统被空转了 |
| 任务拆得过细 | 拆到"打开文件"这种程度，任务就失去了意义 |
| 隐去中断、改写记录 | 监督的全部价值建立在记录的真实性上 |
| 依赖意志力而非机制 | 意志力是消耗品，机制才是基础设施 |
| 一次中断后重设整个计划 | 重设计划是"用计划代替行动"，最容易上瘾 |

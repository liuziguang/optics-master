## 每一级的通过标准（都一样）

L1 到 L5，判对错**只用同一个方法：代特殊值**。

| 代什么 | 应该得到 | 为什么 |
| --- | --- | --- |
| `Δφ = 0` | 合振幅 `= 2A` | 两列完全同相，振幅相加 |
| `Δφ = π` | 合振幅 `= 0` | 两列完全反相，全黑 |
| `Δφ = 2π` | 合振幅 `= 2A` | 转一圈回到原处 |

**三个都对，才算这一级通过。** 有一个不对就停在那一级。

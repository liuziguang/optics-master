# 001 复指数与波

**对应卡片**：W01 · C18

## 目的

用眼睛确认：**复指数取实部就是一个真实的波**。
这是整个光学（干涉、衍射、傅里叶光学）后面要反复用的图像。

## 运行

```powershell
cd D:\Optics_Master\sim

```

## 这张图要你看什么

| 图 | 画的是 | 结论 |
| --- | --- | --- |
| 上 | `cos(x)` 与 `Re(e^(ix))` | **完全重合**，差值为 0 |
| 下 | `sin(x)` 与 `Re(e^(ix))` | **不重合**，相差 π/2 |

脚本会先打印三个"最大值差"的数字，再画图。**先看数字，再看图。**

## 假设与说明

- 纯数学演示，没有物理近似。
- `x` 取一个完整周期（0 到 2π）。
- 第三个数是 1e-16 量级，那是浮点数的机器精度，等价于 0。

## 一个订正记录

这张卡最初写的是"`sin(x)` 与 `Re(e^(ix))` 完全重合"，**这是错的**。
实测两者最大差 1.414。正确对应关系是 `cos(x) = Re(e^(ix))`；
正弦要写成 `Re(e^(i(x−π/2)))` 才重合。
错误在第一次执行时被发现并订正——**这正是本项目要求"先算数字再看结论"的理由。**

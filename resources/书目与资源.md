# 书目与资源

> 原则：**每个阶段主线教材只选一本。** 同时读三本书是长期项目最隐蔽的杀手。

## 1. 主线教材（按阶段选）

| 阶段 | 中文主线 | 英文主线 | 说明 |
| --- | --- | --- | --- |
| S0 地基 | 任意大学物理实验教材 | — | 重点是误差与单位 |
| S1 几何光学 | 赵凯华《新概念物理教程·光学》 + 郁道银《工程光学》 | Hecht《Optics》 | 赵凯华讲物理图像最好，郁道银偏工程 |
| S2 波动/傅里叶 | 梁铨廷《物理光学》 | Goodman《Introduction to Fourier Optics》 | Goodman 是傅里叶光学的圣经 |
| S3 电磁/偏振 | 《光学》相关章节 | Born & Wolf《Principles of Optics》 | B&W 是经典，但难，配合读 |
| S4 激光/非线性 | 《激光原理》（周炳琨等） | Saleh & Teich《Fundamentals of Photonics》；Boyd《Nonlinear Optics》 | Saleh & Teich 覆盖面最广 |
| S5 量子/统计 | 《量子光学》相关 | Loudon《The Quantum Theory of Light》；Goodman《Statistical Optics》 | Loudon 是标准入门 |
| S6 专题 | 见 `../curriculum/S6-专题与前沿.md` | 同左 | 按方向选 |

## 2. 工具书（不读，只查）

| 书 | 用途 |
| --- | --- |
| Smith《Modern Optical Engineering》 | 工程光学百科，公式、设计、材料应有尽有 |
| Bass《Handbook of Optics》（多卷） | 终极参考，查任何光学数据 |
| Malacara《Optical Shop Testing》 | 光学检测方法大全（刀口、朗奇、干涉、星点） |
| Macleod《Thin-Film Optical Filters》 | 薄膜设计标准参考 |
| Moore《Building Scientific Apparatus》 | 实验室动手圣经：真空、光机、电子、加工 |
| 王之江《光学技术手册》 | 中文工程参考 |

## 3. 实验与动手

| 资源 | 用途 |
| --- | --- |
| 《光学实验》类教材（各高校版本） | 标准实验步骤 |
| Kriege & Berry《The Dobsonian Telescope》 | 自制天文望远镜（动手党首选） |
| Texereau《How to Make a Telescope》 | 经典磨镜指南 |
| 期刊 *Applied Optics* / *Optics Express* / *Optical Engineering* | 找具体装置的实现方案 |
| 厂商应用笔记（Thorlabs / Edmund / 大恒） | 最实用的技术资料，免费且质量高 |

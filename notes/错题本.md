## 八个类型（填"类型"那一列时挑一个）

| 类型 | 什么时候用 | 该做什么 |
| --- | --- | --- |
| **一遍过** | 顺利做出来 | 只记"关键一步"，别写过程 |
| **概念缺口** | 完全没思路，或理解错了某个概念 | 回去看笔记对应那一节 |
| **规则不熟** | 知道该干什么，但记错了规则 | 把规则抄成一句话，进 L3 卡片反复练 |
| **符号与方向** | 正负号、方向、象限、模的正负 | **先画图再写数**——这是你目前最高频的一类 |
| **计算失误** | 思路对，数算错了 | 检查有没有"硬凑漂亮分数"的冲动 |
| **边界与特例** | 特殊值没考虑（Δφ = 0 / π、负方向） | 每次推完**代一个特殊值进去** |
| **推导链断裂** | 中间某一步接不上 | 说明那一层是 ① 或 ② 类问题，走 L2 / L3 |
| **表达不清** | 心里明白，说不出来 | 用【说/写】把结论写成一句话 |
